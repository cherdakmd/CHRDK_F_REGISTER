# CHRDK F Register

Server-side мод регистрации и временного whitelist для **Fabric 26.3**. Игроку не нужен клиентский мод.

## Что происходит при входе

Если игрок не в whitelist, мод не пускает его в мир и заменяет стандартную причину отключения на экран с двумя кликабельными вариантами:

- **Twitch / фоллов** — игрок подписывается на заданный канал, входит в Twitch на защищённой HTTPS-странице и подтверждает подписку.
- **DonatePay / донат** — игрок переводит от **250 ₽**, указав точный Minecraft-ник в имени донатера. Мод сверяет успешную транзакцию через DonatePay API.

Любой из способов сам по себе выдаёт доступ (**Twitch ИЛИ DonatePay**). После подтверждения игроку нужно подключиться к серверу ещё раз.

### Сроки и отмена доступа

- **Twitch:** доступ поддерживается, пока follow активен. Мод проверяет его раз в `twitchCheckSeconds` (по умолчанию 10 минут), продлевает 30-дневный lease и снимает выданную им запись whitelist после подтверждённой отписки. Если Twitch временно недоступен, мод не отзывает доступ из-за одной ошибки API.
- **DonatePay:** успешный донат от 250 ₽ даёт 30 дней. Повторный подходящий донат продлевает срок.
- Если у человека одновременно активны обе причины, отписка не отключит действующий донатный доступ.

Имя донатера сверяется с Minecraft-ником строго посимвольно, с учётом регистра и без обрезки пробелов. Других совпадений (частичного имени, комментария к платежу) нет.

## Совместимость

- Minecraft **26.3**, Fabric Loader **0.19.5+**, Java **25+**.
- Fabric API — для сборки настроено `0.162.0+26.3`.
- Мод устанавливается **только на выделенный сервер**. Клиентам достаточно обычной сборки Minecraft/Fabric 26.3.
- Мод не зависит от Archers, Better Combat, MineColonies и остальных модов сборки; он меняет только обработку vanilla whitelist и не добавляет предметы/блоки.
- Используй официальный аккаунт Minecraft и `online-mode=true`. В offline/cracked-режиме ник можно подменить, поэтому автоматическую выдачу доступа включать небезопасно.
- До запуска включи vanilla whitelist (`white-list=true` в `server.properties` или команда `/whitelist on`): мод управляет записями через vanilla-команды и намеренно не отключает whitelist.

## Сборка

Нужен JDK 25. Из корня репозитория:

```bash
./gradlew build
```

Готовый файл появится в `build/libs/chrdk-f-register-1.0.0.jar`. Положи его в `mods/` на сервере рядом с Fabric API и перезапусти сервер.

## Настройка

При первом старте появится `config/chrdk_f_register.json`. Заполни его **на сервере** и перезапусти сервер:

```json
{
  "publicBaseUrl": "https://register.example.ru",
  "bindAddress": "127.0.0.1",
  "webPort": 8787,

  "twitchClientId": "",
  "twitchClientSecret": "",
  "twitchChannelLogin": "",
  "twitchChannelId": "",

  "donatePayApiToken": "",
  "donatePayPaymentUrl": "",

  "minimumDonationRubles": 250,
  "grantDays": 30,
  "ticketLifetimeHours": 168,
  "donatePollSeconds": 60,
  "twitchCheckSeconds": 600
}
```

### Публичная HTTPS-страница обязательна

Whitelist не даёт незнакомому игроку зайти и выполнить `/register`, поэтому регистрацию обслуживает встроенная страница. Для Twitch требуется публичный HTTPS callback. Сам HTTP listener по умолчанию доступен только локально на `127.0.0.1:8787`; поставь перед ним reverse proxy. Например, Caddy на той же машине:

```caddyfile
register.example.ru {
    reverse_proxy 127.0.0.1:8787
}
```

Настрой DNS для `register.example.ru` на сервер, открой HTTPS/443 и укажи **этот же HTTPS-адрес** в `publicBaseUrl` без завершающего пути. Проверка доступности: `https://register.example.ru/health` должна вернуть `ok`.

Если reverse proxy находится на другой машине/в контейнерной сети, задай подходящий `bindAddress` и закрой порт от постороннего доступа firewall-ом. Не выставляй HTTP listener в интернет без HTTPS.

### Twitch

1. Создай OAuth-приложение Twitch.
2. Добавь в список OAuth Redirect URL ровно:
   `https://register.example.ru/oauth/twitch/callback`
3. Внеси `twitchClientId`, `twitchClientSecret` и `twitchChannelLogin` в конфиг. `twitchChannelId` можно оставить пустым: мод получит его через Helix.
4. Мод запрашивает у игрока только scope `user:read:follows`; токены нужны серверу для повторной проверки отписки и хранятся локально.

### DonatePay

1. Внеси API-токен аккаунта в `donatePayApiToken`.
2. В `donatePayPaymentUrl` укажи свою страницу оплаты DonatePay.
3. Оставь проверку API не чаще раза в 20 секунд; рекомендуемое значение — 60 секунд.

Мод читает только успешные транзакции типа `donation`. При первой проверке он запоминает последнюю существующую транзакцию, поэтому старые платежи не выдадут проходку новым заявкам. Для автоматической привязки у игрока должен быть действующий ticket: его сервер создаёт, когда игрок хотя бы раз пытается подключиться.

## Команды администратора

Доступны операторам с уровнем прав 3+ и из консоли:

```text
/fregister status
/fregister revoke <ник>
```

`revoke` удаляет регистрацию и управляемую модом запись whitelist. Если игрок был вручную добавлен в vanilla whitelist до регистрации, его ручная запись останется. Настройки применяются после рестарта сервера.

## Данные и секреты

Токены Twitch, данные заявок, сроки доступа и курс DonatePay хранятся в `config/chrdk_f_register-data.json`. На POSIX-системах файл создаётся с правами `600`. Делай резервную копию вместе с сервером, не публикуй этот файл, OAuth secret или DonatePay API token и не клади их в Git. При переносе сервера скопируй файл данных и `whitelist.json`.
