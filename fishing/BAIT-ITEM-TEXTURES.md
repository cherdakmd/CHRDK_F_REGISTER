# Текстуры новых приманок Fishing

У каждого из трёх видов приманки собственная 32×32 модель. Независимая настройка
`textures.bait-items: false` выключена по умолчанию и считывается при запуске
плагина. Включать её следует только после обновления и проверки объединённого
ресурс-пака; без него вместо модели может появиться отсутствующая текстура.

Модель добавляется только при создании новых подписанных приманок. Подпись,
тип, цена, количество, применение и проверка предмета не зависят от модели.
Уже выданные предметы не переписываются и по-прежнему распознаются. Установка
флага не модифицирует снимки покупки/выбора в журнале; незавершённые операции
должны восстанавливаться по тем снимкам, с которыми были подготовлены, а не
пересоздаваться из нового шаблона. Выключение флага не удаляет модель с уже
выданной приманки, поэтому прежний пак нельзя убирать без плана совместимости.

Автотесты проверяют имена моделей, подпись и чтение предметов при обеих
настройках. Проверка отображения в клиенте и восстановления с новым вариантом
предмета на сервере ещё не проведена. Перед будущим обновлением сохранить
согласованную копию миров, playerdata, банка и `plugins/CHRDK_*`, включая ключи,
базы и WAL/SHM; не запускать аварийные эксперименты на рабочем сервере.
