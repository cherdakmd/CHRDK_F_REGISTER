# Fishing Horizons — подготовка к выпуску

Проверено по состоянию кандидата `2.0.26-rc.33` на коммите
`ce05b2cea0c4565fc8a7f8ee79b1b64641908770`. Это **не релиз** и не разрешение на
установку. Название согласовано владельцем для GitHub и будущего поста; пост
ещё не публиковался. Не выпускать RC под видом стабильной версии.

Решение о стабильном выпуске зависит от `STABLE-RELEASE-GATE.md` и достоверных
результатов проверок, а не от названия версии. Если владелец изменит решение и
захочет публичный **предварительный** выпуск, это отдельное действие с явной
маркировкой рисков; текущего согласия на такой выпуск нет.
