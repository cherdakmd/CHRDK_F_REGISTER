# Картинки со статистикой и этап «Стена сообщества»

Статус: **картинки и тексты 2.0.6 реализованы**, публикация соц-карточек на
стену сообщества — **отдельный следующий этап**; этот документ — подробная
инструкция для его реализации. Ежедневные карточки статистики уже выходят и в
беседу, и на стену (см. `docs/VK_WALL_DIGEST.md`).

## Единый визуальный стиль

* PNG **1280×720**, тёмный фон `world-background.jpg` с градиентом, логотип
  «ЧЕРДАК» слева сверху, под ним бейдж номинации («ШАХТЁР ДНЯ», «Полезный
  совет» и т.д.).
* Шрифты — DejaVu Sans / DejaVu Sans Bold (`vk/src/main/resources/assets/`
  для Java2D, `/usr/share/fonts/truetype/dejavu` для PIL).
* Подвал: короткая черта `64,645 → 118,645`, слева слоган **«ТВОЙ МИР. ТВОЯ
  ИСТОРИЯ.»**, справа — **контакт сервера: `4rdk.ru-mc.ru · версия 1.21 и
  выше`**. Контакт обязателен на каждой картинке и в тексте каждой записи;
  строку меняют ключи `wall-daily-cards.contact` / `wall-digest.contact`
  (Java) и константа `CONTACT` в `tools/social/content.py` (соц-карточки).
* В тексте записи последняя строка — служебный маркер `#chrdk_<hex>` для
  ручной сверки и дедупликации.

## Текст записи

Формат текста стены/беседы (пример для номинации игрока):

```
CHERDAK · ШАХТЁР ДНЯ · 3 ноября 2026

★ Alex
1842 блока · 96 алмазов

ТВОЙ МИР. ТВОЯ ИСТОРИЯ.
4rdk.ru-mc.ru · версия 1.21 и выше
#chrdk_abc123def456
```

Текст соц-карточек (`tools/social/content.py`): заголовок вида «Совет CHERDAK ·
…», выдержка из вики, ссылка «Подробнее», строка «Подсказка по стандартным
правилам CHERDAK. Точные условия и доступность проверяйте в игре.», затем
контакт и маркер. Для новостей релизов — «Это выпуск комплекта. Установка на
игровой сервер выполняется отдельно.» Форматы не менять: на них завязаны пины
тестов.

## Приватность

На карточках номинаций видны **ники победителей и результат** — явное решение
владельца; opt-out беседы к ним не применяется. Никогда не публикуются: суммы
реальных платежей, SKU, UUID, IP, координаты, время входа, реальные счета.
`show-values: false` убирает и числа (остаются подписи). Дайджест и «День
сервера» — только обезличенные агрегаты; имена лидеров в дайджесте выключены
по умолчанию (`wall-digest.show-player-names`).

## Этап «Стена сообщества» — инструкция к реализации

Цель этапа: соц-карточки (советы, новости релизов) из GitHub Actions публикуются
на **стену сообщества** так же, как это уже делает плагин для девяти
ежедневных записей.

1. **VK API и права.** Нужен `community.group-id` и `community.access-token`
   с правом `wall` (уже используется плагином). PNG на стену в режиме `photo`
   дополнительно требует `community.photo-user-token`
   (`photos.getWallUploadServer` → `photos.saveWallPhoto` → `wall.post` c
   `attachments`); без него — авто-fallback на `text` (запись текстом). Общий
   allowlist хостов загрузки: `vk.com`, `userapi.com`, `vkuserphoto.ru`, только
   HTTPS. Токены — только в секретах репозитория/конфиге, никогда в URL и логах.
2. **Публикация.** `wall.post` текстом (`message`) или с вложением; подпись
   «обсудить — https://vk.me/join/…» добавляется к записи стены
   (`withDiscuss` в `VkConfig`, уже реализовано для плагина). Карточка в беседу
   отдельно тем же PNG **без** подписи «обсудить» (реализовано в
   `tools/social/publisher.py`).
3. **Идемпотентность.** Маркер `#chrdk_<hex>` в тексте — уже есть в обоих
   конвейерах. Для соц-конвейера дедуп держит журнал в GitHub Issues
   (`tools/social/publisher.py`/`max_publisher.py`): повторный запуск workflow
   не создаёт дубль; незавершённая отправка (`posting`) требует ручной сверки,
   а не тихого повтора. Плагин хранит свои отметки в `wall-digest.json` /
   `daily-cards.json`.
4. **Расписание и лимиты.** У сообщества действует flood control VK (error 9):
   девять постов плагина в сутки — верхняя граница. Соц-посты на стену
   добавлять в те же слоты 12:00/18:00, не создавая новые; `random_id` у
   сообщений беседы и `guid` у записей стены обязаны быть стабильными на
   повторных запусках. Суммарно не больше одной записи в слот.
5. **Тексты и картинки — без изменений.** Форматы из разделов выше уже
   зафиксированы пинами тестов; этап стены не должен менять ни `Post.text`,
   ни рендер `tools/social/cards.py`, ни Java-карточки.
6. **Чек-лист внедрения:**
   * `tools/social/publisher.py` — добавить режим стены (wall-пост с подписью
     «обсудить») рядом с сообщением беседы, с общим allowlist и fallback text;
   * `tools/social/run.py` — флаги/переменные окружения включения стены
     (по образцу `MAX_AUTOPUBLISH_ENABLED`), выключено по умолчанию;
   * `tools/social/test_social.py` — пины: подпись «обсудить» только на стене,
     маркер последней строкой, отсутствие приватных данных, дедуп по журналу;
   * документация: `docs/automation/max-publications.md` и эта страница;
   * проверка вручную: `/vkadmin testpost wall` (плагин) и одноразовый
     workflow с dry-run выводом `post.txt`/картинки (соц-конвейер).
