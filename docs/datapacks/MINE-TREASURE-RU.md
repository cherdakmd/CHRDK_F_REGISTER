# Mine Treasure v1.6.5 RU — серверная интеграция CHRDK_Core

Это **не Incendium** и не новый перевод: речь о приложенном архиве
`mine-treasure-1.6.5-ru.txt`, который на самом деле ZIP с уже готовым русским
текстом. Интеграция добавляет в ядро мягкое автообнаружение и включение пака в
мире; содержимое датапака, команды, лут и перевод **не переписываются**.

## Что сделано

1. `tools/datapacks/install_mine_treasure.py` проверяет присланный архив и
   копирует его в `<мир>/datapacks/mine-treasure-1.6.5-ru.zip`. Исходное
   расширение `.txt` допустимо: тип определяется по сигнатуре ZIP, а не по имени.
2. `CHRDK_Core` через секунду после `onEnable()` обращается к Paper
   `DatapackManager`, ищет id `file/mine-treasure-1.6.5-ru.zip` и, если пак
   найден, но выключен, один раз вызывает `Datapack#setEnabled(true)`.
   Уже включённый пак не трогается; отсутствующий пак не создаётся.
3. Обращение к Paper API сделано через рефлексию: если в конкретном Purpur
   `26.3.build.2647-experimental` метода нет, ядро не падает, а пишет в журнал
   команду ручного включения.
4. `tools/datapacks/test_install_mine_treasure.py` и
   `MineTreasureIntegrationTest` проверяют валидацию/id/решение без живого
   сервера; новый unittest-шаг добавлен в CI рядом с проверкой Incendium.

**ZIP в репозиторий не добавлен.** `LICENSE.md` внутри пака (© 2026 Frozytime)
разрешает использование на публичном сервере с указанием автора и ссылкой на
оригинальную страницу, но прямо запрещает выкладывать пак на другие сайты или в
составе большего пакета/модпака без явного разрешения. Поэтому публикуем только
код интеграции, документацию и контрольную сумму; сам файл владелец сервера
кладёт локально. Оригинальные страницы: [Planet Minecraft](https://www.planetminecraft.com/data-pack/mine-treasure/),
[Modrinth](https://modrinth.com/datapack/mine-treasure), [mine-treasure.com](https://mine-treasure.com).
Перед включением на публичном сервере выполните требование лицензии об
упоминании Frozytime и ссылке в описании сервера.

## Установка

1. **Остановите сервер и сделайте резервную копию мира.** Скрипт пишет в
   `<мир>/datapacks`, но не проверяет, что сервер выключен.
2. Проверьте архив без копирования:

   ```bash
   python3 tools/datapacks/install_mine_treasure.py --check \
     --source /tmp/arena-coding-uploads/mine-treasure-1.6.5-ru.txt
   ```

3. Установите ZIP. `--world` принимает папку мира с `level.dat` либо корень
   сервера; `level-name` читается из `server.properties`.

   ```bash
   python3 tools/datapacks/install_mine_treasure.py \
     --source /tmp/arena-coding-uploads/mine-treasure-1.6.5-ru.txt \
     --world /path/to/server
   ```

   Повторный запуск с тем же архивом ничего не перезаписывает. Если в
   `datapacks` уже лежит другой файл с этим именем, скрипт остановится;
   `--force` заменяет его только после явного указания. Для другой сборки
   передайте её `--sha256` (или `--sha256 ''`, чтобы пропустить сравнение).
4. Запустите сервер с обновлённым `CHRDK_Core`. Проверьте журнал и
   `/datapack list enabled`. Ожидаемый id:

   ```text
   file/mine-treasure-1.6.5-ru.zip
   ```

   Если Paper API недоступен, включите вручную и перезагрузите ресурсы:

   ```text
   /datapack enable "file/mine-treasure-1.6.5-ru.zip"
   /minecraft:reload
   ```

## Конфигурация `CHRDK_Core/config.yml`

Старый `config.yml` без секции работает со значениями по умолчанию; миграция
схемы не требуется.

```yaml
integrations:
  mine-treasure:
    auto-enable: true
    refresh-on-start: false
    file-name: "mine-treasure-1.6.5-ru.zip"
    pack-id: ""
```

- `auto-enable: false` — ядро не вызывает `setEnabled(true)`.
- `refresh-on-start: true` — если пак не найден, дополнительно вызывается
  `DatapackManager#refreshPacks()` и поиск повторяется. По умолчанию выключено,
  чтобы не дёргать переоткрытие репозитория паков на каждом старте.
- `pack-id` — только для паков, зарегистрированных другим Paper-плагином;
  пустое значение даёт `file/<file-name>`.

`setEnabled(true)` в Paper сам инициирует `reloadResources`; отдельный
`Server#reloadData()` из CHRDK не вызывается. На первом включении это может
дать заметную паузу перезагрузки ресурсов.

## Что проверить на живой сборке

Интеграция не заменяет smoke-тест. В присланном паке стоит отдельно проверить:

- **43 переопределённых ванильных `loot_table/blocks/*.json`** (камень, руды,
  базальт и др.): они меняют добычу блоков и могут пересечься с другими
  модулями CHRDK, которые тоже реагируют на ломание блоков.
- **1132 блока `minecraft:set_attributes`** в таблицах лута: ранее
  зафиксированный `ItemAttributeMerge` сохраняет эти модификаторы при
  наковальне/крафте/кузнечном столе, но не проверяет внутренний формат самого
  датапака.
- 29 записей с атрибутом `water_movement_efficiency` без префикса
  `minecraft:` и 5 записей, где `slot` задан массивом, а не строкой: сверить с
  кодеком 26.3 и журналом загрузки датапака.
- `#minecraft:load` → `mt:init` регистрирует scoreboard-цели и
  `forceload add 0 0 0 0` в обычном мире; `#minecraft:tick` → `mt:tick`
  выполняет функции для всех игроков и помеченных сущностей.
- Русские названия/описания предметов, достижения, книгу и команду настроек
  пака; язык клиента не должен требоваться для текста, зашитого в JSON.

## Границы и статус проверки

- Уровень интеграции выбран как «установка локального ZIP + автовключение из
  ядра»; уточняющий вопрос пользователю остался без ответа, поэтому этот выбор
  не считается отдельно согласованным. Альтернативы (bootstrap
  `DATAPACK_DISCOVERY`, патч содержимого пака, публикация ZIP в репозитории)
  не реализовывались.
- Живой Purpur, RCON, Java/javac, Gradle и Purpur API jar в песочнице
  отсутствуют. Paper `main` использовался только как справочник API и **не равен**
  Purpur `26.3.build.2647-experimental`. Новые Java-классы не скомпилированы и
  JUnit не запускались; Python-тесты, статический разбор Java, wiki/freshness и
  `git diff --check` выполнены.
- rc.9, тег `vk-v1.5.2-rc.9`, Release, `Latest`, Pages и PR не трогались.
  Слой совместимости атрибутов `cd09e64` не изменялся.
- Это не «проверено на сервере» и не гарантия игровой совместимости: после
  реального старта нужны `/datapack list enabled`, журнал загрузки, добыча из
  камня, выдача предметов и наковальня/тир-форж/чары на предмете Mine Treasure.
