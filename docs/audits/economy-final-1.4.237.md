# Итоговый реестр экономики — 1.4.237 / API 25

Сквозной повторный просмотр ядра и всех 29 аддонов: денежные поля, YAML-выходы,
ItemStack/DIAMOND/BLOCK, inventory charge, dropItem, callback settlement, импорты,
квитанции и recovery. Это аудит исходников, не сверка остатков рабочего сервера.
Ранее открытые переходы 232 закрыты в 233–237; текущий реестр заменяет их статус.

## Повторный поиск и границы

- Неиспользуемые физические DiamondWallet в Teleports/Lottery удалены. Активные
  платежи не вызывают их и не имеют fallback на них при отказе банка.
- Оставшиеся DIAMOND-иконки GUI не являются выдачей. DiamondCash/BankCashInventory
  относятся к явным банковским физическим обменам с journal/witness.
- Руда, урожай, натуральные дропы блоков/рыбалки, материалы метеорита без личного
  получателя и именные трофеи — ресурсы мира, не неявное начисление личных денег.
  Добыча ресурсов остаётся на земле, как и требовалось. Запрет money drops касается
  финансовых оплат/выручки/наград, а не отмены ванильного предмета DIAMOND в мире.
- Все обычные денежные элементы Daily/Treasure отделены до native-передачи;
  named treasure diamond не проходит plain-классификатор и не обналичивается.
- Boss/Event источники сохраняют per-event frozen award до банка, независимые
  namespaces; повтор/новая цена не переплачивают. Доходы не расходуются из source.
- Сохранены физические рецепты Enchants и собственные прогрессии охоты/кладов.
  Внешний Vault-провайдер и сторонние плагины не объявляются частью Core `/bal`.

## Долговечность и отказы

Принятое обязательство сохраняется до выплаты; банк подтверждает только cumulative
положительную delta. Cap/unknown/unavailable оставляют остаток. Возврат collective
reserve не переводится случайно лидеру. Lineage/ACK запрещает незаметное создание
пустого источника после потери Core. IO-неопределённость не доказывает отказ.
Нативные инвентарь, мир и independent source-файлы не распределённая транзакция;
неопределённый эффект удерживается для явной сверки, а не повторяется.

Daily EXECUTING/native checkpoint/ACK проверяются production executor-тестами;
Root checkpoint проверяется с queued old snapshots и отказом записи. Daily,
Treasures и dynamic Boss/Event sources проверяются с реальным BankStore:
freeze, restart, spent/retry, cap, unavailable, unknown UUID, corrupt/refusal.
Общий Gradle build обязан охватить Root + 29 модулей перед публикацией архива.
Ручного live crash-test/установки на рабочем сервере не выполнялось.

Документы отдельных волн 224–236 остаются историей проверок на их дату;
их старые «релиз заблокирован» не являются текущим статусом реализации.
Операционные инструкции: [общие заметки 237](../releases/1.4.237.md).
