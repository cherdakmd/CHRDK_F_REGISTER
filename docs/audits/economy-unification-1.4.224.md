# Единый личный алмазный счёт — рабочая проверка 1.4.224

Срез до изменений: `9ea08049ddf601ae72a37f4682accff3cacf73cb` (1.4.223/API 15).
Проверены ядро и все 29 аддонов из settings.gradle: денежные поля, хранилища,
платёжные вызовы и прямые выдачи/списания DIAMOND/DIAMOND_BLOCK.

осколки и настоящие ингредиенты рецептов не конвертируются. После завершения

## Выполненная первая часть 224

- API 16: зарегистрированный источник доходов с долговечным UUID; раздельные
  пространства Lottery/CommonGoals; банк хранит подтверждённый cumulative total
  на ключ источника и UUID получателя. В банк поступает только положительная delta.
- Накопительный source total сохраняется **до** зачисления; успешная выплата не
  удаляет total. Это технический журнал обязательств, не второй расходуемый кошелёк.
- При cap подтверждается только поместившаяся часть; непогашенная delta остаётся
  правом на выплату. При полностью заполненном счёте нет нового подтверждения. Новый доход после
  выплаты — новая delta, а не повторное использование одноразовой квитанции.
- Источник нельзя незаметно сбросить: другая lineage, другой UUID, уменьшенный total,
  недоступный банк или исчезнувшая регистрация останавливают выплату. Имя цели не
  превращается в вычисленный offline UUID; используются авторизованный владелец
  либо достоверная запись Core/cache. Неизвестный владелец остаётся в источнике.
- Сумма+квитанция пишутся одним bank.json с fsync/atomic replace/directory sync.
  Ошибка записи блокирует банк; false не трактуется как доказанная неоплата.
- Lottery переносит только остававшийся невыплаченным приз, не фонд текущего тиража
  и не историю. Новые розыгрыши увеличивают source total. Физическое снятие запрещено
  после обновления схемы; /lottery claim повторяет зачисление в /bal.
- CommonGoals сохраняет завершение и распределённые доходы одним source-файлом под
  одним замком, до вызова банка. /goals claim не удаляет запись и не выдаёт предметы.
- Новые ключи сообщений не переиспользуют старые обещания выдачи алмазов в инвентарь.

## Этап 227

Guilds: создание и взнос через bank-first WAL, снятие — атомарный treasury-debit
с cumulative-entitlement для /bal. Общая казна/ставки не принадлежат лидеру;

## Этап 228

Монетарные вехи Skills/Achievements и коллекций Artifacts/TierForge перенесены
в общий банк через `milestone-awards.json`: отметка и сумма записываются вместе,
исторические выданные вехи импортируются без новой выплаты. Доставка delta
при cap/недоступности/неизвестном UUID не удаляет обязательство.
[Протокол и границы гарантии 228](../releases/1.4.228.md).
API 20 также проверяет известность UUID на общем creditEntitlement, не только
в новом адаптере. Старые игровые бусты/асинхронный прогресс не объявляются ACID с банком.
