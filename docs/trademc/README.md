## Новый товар «Всё включено» — 899 ₽ / 30 дней

```text
pass shopbuy %username% all-inclusive
```

Ранг V + один пакет +8 домов + пять каталожных шлейфов + пять платных цветов
+ эффект входа + премиум-трек. Все дополнения этой покупки на 30 дней; отдельный
пропуск по-прежнему продаётся на 90 дней. V также открывает два эксклюзивных
шлейфа. Первый набор без других пакетов даёт **20 домов**. Существующие покупки
учитываются, не заменяются. Повтор продлевает ранг/косметику и добавляет ещё
один независимый пакет домов. Сначала проверяется весь состав; при невозможной
доставке — ручная сверка, не выдача половины набора. Постоянному V набор не
выдаётся. Возврат гибрида — ручной разбор, `shoprevoke` не отзывает его частично.

Не добавляйте команды составляющих в карточку: это одна продажа 899 ₽.
Для старого сервера сначала обновите плагины и добавьте новый блок в
`shop.products` по [инструкции 1.4.198](https://github.com/cherdakmd/CHRDK_F_REGISTER/blob/arena/7bbabe8a-chrdk-f-register/docs/releases/1.4.198.md).

## Главное для панели

Команда товара: `pass shopbuy %username% <id_товара>` — **без `/`**, по RCON.
В TXT уже стоят реальные ID всех 26 товаров: заменять их вручную не нужно.
`%username%` должна заменяться самой панелью на игровой ник: проверьте
поддерживаемую подстановку в своей настройке TradeMC. Чужую панель этот
репозиторий не проверяет. `payment=` и номер заказа для RCON включённого
магазина **не нужны**. Для одного платежа выполняйте **только одну** команду,
не основную вместе с альтернативной `shoppay`.

Включите `trademc.enabled: true`, защитите RCON паролем/firewall и сверяйте
доставки с реальными платежами в кабинете. Без номера заказа/API плагин не
проверяет поступление денег и не отличает повтор команды от новой покупки.
Подробные настройки, подарки и ручная консоль описаны в конце TXT.

## Состав

- 10 карточек рангов: I–V, отдельно 30 и 365 дней.
- Дома, 5 отдельных шлейфов, эффект входа, 5 отдельных цветов ника.
- Боевой пропуск **90 дней**, набор шлейфов и «Весь вид».

Настройки товаров — `src/main/resources/config.yml → shop.products`.
Цифры в описаниях рангов также берутся из стандартных конфигов Teleports,
Claims, Auction и настроек надписей/бонусов ядра. На сервере с собственными
настройками сначала приведите витрину в соответствие с ними.
Платные цвета не входят в ранг V; игровые награды дают отдельный XP-буст,
а не платные товары. Боевой пропуск уже доступен активным рангам IV–V.

## Дома: +8 за каждую покупку

Каждая покупка `homes-plus` добавляет **8 мест на собственные 30 дней**.
Пакеты складываются с базовым лимитом текущего ранга и друг с другом, без
общего игрового потолка. Ранг V и два пакета: **12 + 8 + 8 = 28**.
У каждого пакета свой срок; повторная покупка не продлевает старый пакет.
При истечении пакета или ранга сохранённые точки не удаляются: существующими
можно пользоваться, новые сверх действующего лимита создавать нельзя.
Число пакетов читается из оплаченных покупок ядра, не из LP-прав.
Старое одиночное право переносится как один пакет на весь оставшийся срок;
по суммарному сроку прежних продлений количество покупок не угадывается.

## Повторная сборка / проверка

Linux, Python 3.10+, шрифт DejaVu Sans (`fonts-dejavu-core` в Ubuntu):

```bash
python3 -m pip install -r tools/trademc/requirements.txt
python3 tools/trademc/build.py --build
python3 tools/trademc/build.py --check
python3 -m unittest discover -s tools/trademc -p 'test_*.py' -v
python3 tools/trademc/build.py --zip
```

ZIP появится в `build/trademc/chrdk-trademc-<версия>.zip`; этот путь не хранится
в Git. Можно указать `--zip --output /путь/магазин.zip`. Состав/порядок/даты
элементов ZIP фиксированы, содержимое проверяется перед упаковкой. Для каждого
SKU используется собственное изображение; ранги оформлены на основе уже
существующих иллюстраций `docs/ranks/shop/art/`, остальные товары — оригинальные
процедурные пиксельные иллюстрации. Внешние ресурсы при сборке не загружаются.

Build CI сверяет связи товаров между модулями, TXT/Markdown/аудит/манифест/картинки с каталогом. Release CI повторяет проверки,
собирает комплект и публикует его отдельным ZIP рядом с единым архивом плагинов.
Старый комплект из шести картинок `docs/ranks/shop` — исторический, для нового
магазина используйте именно этот каталог из 26 карточек.
