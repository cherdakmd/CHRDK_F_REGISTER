# Примеры постеров CHRDK_VK

Три примера 1280×720 для пререлиза `vk-v1.5.2-rc.5` и постеров стены.

- `preview-news-card.png` — карточка новости о пререлизе. Отрендерена штатным
  `tools/social/cards.py` (те же байты, что ушли в беседу ВК с объявлением).
- `preview-wall-digest.png` — постер «ИТОГИ ДНЯ» для стены сообщества. Это
  построкаовая реплика `vk/src/main/java/ru/cherdakmd/chrdkvk/WallDigestCard.java`
  на Pillow: тот же фон, градиент, шрифты из `vk/src/main/resources/assets/`,
  координаты и данные из `WallDigestCardTest`. Дата нарисована ниже бейджа
  (базовая линия 236 вместо 194), а отчёт содержит шесть блоков, включая
  добытые блоки, алмазы и победы над монстрами. Локально Java2D недоступен,
  поэтому байты отличаются от того, что нарисует плагин на сервере, только
  сглаживанием текста.

- `preview-daily-card.png` — пример персональной карточки «Самый богатый» с
  ником игрока (одна из четырёх номинаций, которые вместе с дайджестом дают
  пять постов на стене в сутки). Тоже Pillow-реплика `DailyPlayerCard.java`.
  Остальные три карточки отличаются бейджем, ником и строкой результата.

Превью не являются ассетами релиза: в `vk-v1.5.2-rc.5` ровно один ассет —
`chrdk-vk-1.5.2-rc.5.jar`.
