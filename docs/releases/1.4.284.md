# 1.4.284-rc.1 — RC16 поверх стабильного 1.4.283 (пререлиз)

**Пререлиз для проверки на изолированном staging. Не стабильный выпуск и не
разрешение на автоматическую установку.** Стабильной версией остаётся **1.4.283**.
Игровой smoke настоящего Minecraft-клиента, native `CraftItemStack`/NBT-кодек
на живом сервере, сохранение playerdata и нагрузочное измерение MSPT
**не выполнялись**. Minecraft-сервер, RCON и TradeMC не изменялись.

## Что сделано

Ветка `arena/664c2727-chrdk-f-register` начинается с `main` после релиза
1.4.283 (`bc8516e7`). В неё влиты **все 45 коммитов** пререлиза
`v1.4.282-rc.16` (`71aa86e5`, ветка `arena/49bc75f7`), ранее собиравшихся
поверх старого `main` `df63af7`. Общий предок — `df63af7`; слева 18 коммитов
(PR #54 + релиз), справа 45. Номер **1.4.282 по-прежнему не используется**
для стабильного комплекта: один номер не должен обозначать разные исходники.
Версия `gradle.properties` — `1.4.284-rc.1`, **Core API42**.

### Влитое из RC1–RC16

- **Кузня**: раздел `/shop` → «Кузня» (слот 46), `/shop forge` (алиас
  `kuznya`), ровно восемь whitelist-SKU `ascend, temper, reforge, seed, repair,
  inscribe, remove, name` по ценам `128, 96, 160, 64, 24, 192, 32, 16` алмазов.
  `forge-shop.enabled / operations.<sku> / prices.<sku>`; неверная цена
  **закрывает** SKU, обратной скупки нет.
- **Frozen grant**: `ShopExchange` несёт nullable native-снимок одного
  PDC-прототипа; Core `ForgeMarketCatalog` проверяет whitelist, материал,
  `forge_material_v1`, канонический UUID искры и `max-stack-size=1`.
  `ShopInventory.replay` воспроизводит платёж и exact `isSimilar` вставку
  клонов со сравнением полного native after. Используются прежние
  `ShopStore`/`BankStore` WAL, нового кошелька нет; recovery принятой сделки
  не требует живого TierForge, текущих цен или нового источника расходников.
- **Искра `seed`**: только `QualifiedHuntKillEvent`, 0.5% на ур.1 → 1% на
  ур.30 → 3% на элитном ур.30. Четыре остальных новых расходника по умолчанию
  **только в магазине**. Наковальня: искра 8, ремонт 6, ковка I 10, удаление
  ковки 4, кличка 2 — **уровнями XP, не очками**. Сохранены preview, ПКМ-выбор,
  полная цена XP, отложенная exact-snapshot ревалидация, anti-spam и rollback.
- **Оформление клана**: aurora / shine / pulse / prism / flame, один общий
  таймер TAB (общее обновление шапки можно отключить
  `tablist.refresh-ticks: 0`), кадр чата фиксируется на момент отправки,
  право применения только у текущего главы по действующим личным лицензиям.
- **Справочники**: handbook всех 65 артефактов, расширенный каталог чар,
  `/enchants help`, `/enchants info`, миграции stock-текстов только при точном
  совпадении, legacy-снимки сообщений RC7/RC8/RC15.
- **BattlePass**: алмазные награды и снятие потолка накопленного буста,
  миграция стока с backup и atomic-записью, TAB-диагностика.

### Сохранённое из 1.4.283

Книги кастомных и ванильных чар в алмазном магазине (118 книг, два раздела,
скупка только с меткой `SHOP`), единая проверка `conflictGroup`, все восемь
активных ремёсел с доходом алмазов (~1 за 100 XP, дробный остаток, 9999/день,
`xpPercent` усиливает и XP и доход, WAL без двойной выплаты), Plasmo Voice
в 42-м автосообщении и 10-й странице книги-гида, точки дома только на своей
территории (владелец привата или действующий арендатор, `bed`, закрытый `/home`
к старым точкам), фиксы VK-news и BlockState Incendium.

**Матрица живого серверного smoke Кузни — «НЕ ПРОВОДИЛСЯ»**, см.

для Minecraft playerdata и разных плагинных файлов.

## Переход и откат

1. Не применять к production. Отдельная staging-копия и полный backup:
   папки `CHRDK_*`, Core `data.json`/`bank.json` со всеми SHA/журналами,
   `shop-data.json`, `tierforge stats.yml`, `battlepass-data.json`/
   `battlepass-money.json`, `clan-styles.json`, миры и playerdata.
2. Обновлять **весь комплект совместно**, не смешивать версии Core,
   DiamondShop, TierForge, Hunt, Enchants, BattlePass, Guilds, Teleports,
   Claims и Professions. Не удалять банковские квитанции и WAL-pending.
3. Сверить авторские конфиги (`forge-shop.*`, `books.*`, `income.*`,
   `tablist.*`); не редактировать их параллельно с reload. Ошибки строгой
   миграции не обходить удалением файла.
4. Выполнить матрицу живого smoke до какого-либо стабильного выпуска.
5. Откат — согласованные копии всех модулей и данных из п. 1; данные,
   записанные новой версией, старые сборки могут не прочитать.

Выпуск пререлиза разрешён владельцем. Установка на игровой сервер,
публикация TradeMC и стабильная новость ВК **не выполняются**.
