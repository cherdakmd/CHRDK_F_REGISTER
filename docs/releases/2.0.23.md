# CHRDK 2.0.23 — меню чар

Полный комплект для Purpur 26.3 / Java 25. `/enchants` открывает главное меню аддона: каталог, библиотеку, стол переписчика, проверку предмета, источники, очищение, объединение, защиту, таймеры и справку. Прежний каталог доступен через `/enchants catalog`; прямые команды сохранены.

Поиск предлагает ввести запрос в чат. Библиотека, отчёты и подтверждения используют существующие команды и сообщения. Для `/enchants preview` необходимо открыть наковальню и выполнить команду, как объяснено в меню. Стоимость, права и подтверждения существующих операций не отменяются.

Автоматическая сборка и тесты прошли, но **серверный smoke-тест не проводился**: работа GUI и взаимодействие с другими плагинами на конкретном сервере не проверены. Перед обновлением остановите сервер, сохраните согласованную копию миров, playerdata, настроек, данных плагинов, банка и финансовых журналов. Обновляйте Core и аддоны вместе, без `/reload`; откатывайте вместе с соответствующей копией данных. Релиз не устанавливается на сервер автоматически.

Изменения предыдущего комплекта и ограничения миграций описаны в примечаниях к 2.0.22.
