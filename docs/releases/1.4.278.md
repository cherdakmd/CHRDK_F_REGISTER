# 1.4.278 — приветствия рангов и личное оформление кланов

## Вход и ВКонтакте

У каждого активного ранга I–V — 20 вариантов сообщения о входе (100 оформленных
шаблонов). Выбор случайный, без повторения предыдущего варианта в рамках работы
текущего набора настроек. Анонс выполняется после завершения всей авторизации,
один раз за подключение: повторный /logout → /login не спамит общим чатом.
`ranks.announce-join` отключает анонсы, `ranks.levels[].join-lines` задаёт пул;
пустой список выключает сообщение для конкретного ранга. Старые собственные
`join-line` сохраняются. Только точный сток 1.4.277 заменяется новым набором,
с резервной копией конфига. Без ранга премиальных анонсов нет.

Игроку с любым активным рангом I–V социальное напоминание ВК показывается
не чаще одного раза за подключение. Перечитывание настроек ВК не сбрасывает
эту отметку. У обычных игроков остаётся заданный интервал (по умолчанию 180 секунд).
После подтверждения всех пунктов предложение не выводится. При истечении ранга
возвращается обычная частота. Это только приглашения: пароль, TOTP, ВК-2FA,
доставка кодов и ограничения отвязки не изменены и рангом не обходятся.

## Три отдельных товара

Внутренний каталог Core пополнен тремя личными лицензиями, каждая на 30 дней:

| ID | Товар | Цена |
| --- | --- | ---: |
| `clan-name-style` | Цвет/градиент названия и чат-тега | 189 ₽ |
| `clan-emblem` | Значок клана из разрешённого набора | 179 ₽ |
| `clan-card-frame` | Декоративная рамка карточки в меню клана | 219 ₽ |

Ранг, в том числе V, лицензии не заменяет. Они не добавлены задним числом в
«Всё включено»: состав и цена существующих наборов и купленных прав сохранены.
Новые SKU добавляются в локальный каталог без замены собственных цен и товаров;
совпадающий владельческий ID не перезаписывается. Старые SKU не меняются.
Новые товары **не подготовлены и не опубликованы в TradeMC**: архив прежней витрины
проверяется только на чтение, новые SKU исключены явным `trademc-export: false`.
Цены — настройки внутреннего каталога, не заявление о готовой внешней продаже.

Лицензии принадлежат покупателю, а не клану. Каждый покупатель выбирает один
свой клан для всех трёх украшений; перенести весь выбор можно не чаще раза в
реальные 24 часа (включая первый день после назначения). Выход/исключение покупателя,
истечение или отзыв покупки немедленно убирают его эффект при следующей отрисовке.
Выбор не стирается: при продлении и действующем членстве может снова стать активным.
Роспуск не переносит оформление на другой клан с таким же названием — проверяется ID.
При смене главы права не переходят новому главе: остаются у покупателя.

## Управление

- `/clan style` — лицензии, сроки, варианты и текущая личная привязка.
- `/clan style name aurora` — цвет/градиент (12 вариантов).
- `/clan style emblem crown` — значок (8 вариантов).
- `/clan style frame amethyst` — рамка (6 вариантов).
- Глава применяет свою покупку напрямую. Участник отправляет предложение;
  глава за 2 минуты принимает `/clan style accept Ник`. Покупатель должен быть
  в сети, авторизован и по-прежнему состоять в клане с действующей лицензией.
  Согласие при переносе относится ко всему выбранному оформлению покупателя.
- `/clan style off name|emblem|frame` — снять свой выбранный эффект.
- `/clan style clear name|emblem|frame` — глава снимает выбранный тип со всех
  спонсоров своего клана, не отзывая их личные покупки.

При нескольких спонсорах одного типа показывается последний одобренный вариант
с действующей лицензией. Выбор другого типа не меняет приоритет остальных.
После его отключения/истечения может снова показываться прежнее действующее
оформление другого участника. Снятие эффекта не сбрасывает cooldown переноса.

Название оформлено в /clan info, профиле и карточке GUI; чат-тег — в чате.
TAB сохраняет красное/зелёное обозначение боевого/мирного режима и состояние
ожидания защиты; покупка его не перекрашивает. Рамка не закрывает кнопки меню.
Плейсхолдеры: `%chrdkguilds_styled_name%`, `%chrdkguilds_emblem%`,
`%chrdkguilds_card_frame%`; старые name/tag остаются простыми строками.

Настройки хранятся в `clan-styles.json` аддона Guilds. Запись сериализована вне
игрового потока; успех сообщается только после записи, сбой оставляет старый
выбор. Чтение не ждёт диск. При нечитаемом файле эффекты и изменения выключены,
файл не перезаписывается: восстановите backup, не удаляйте его ради cooldown.
Платные права и сроки по-прежнему принадлежат Core; файла настроек недостаточно
для выдачи косметики. Все пресеты серверные, произвольный MiniMessage не принимается.

## Установка и границы

Перед установкой — backup Core и Guilds, включая покупки и `clan-styles.json`.
Обновлять все основные JAR одной версии; CHRDK_VK — отдельный согласованный JAR.
Core API остаётся 34. Лимиты кланов, земля, казна, тарифы, PvP и экономика не
усиливаются покупками оформления. Основной ZIP: 22 JAR + ОБНОВЛЕНИЕ.txt.
Minecraft-сервер не меняется автоматически; установка отдельно. TierForge не менялся.
