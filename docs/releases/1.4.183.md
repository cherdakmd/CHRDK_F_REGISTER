# CHRDK 1.4.183 — в табе порядок, надписи по желанию

В списке игроков был бардак: сортировка шла только по набитым часам, поэтому
Покровитель с месяцем стажа стоял под Странником, а оплаченный ранг в табе не
значил ничего. Второе — оформление никто не мог выключить: ранг, класс,
гильдия, стример и звание кладоискателя висели в нике всегда, даже если игроку
это мешало.

## Что изменилось

- **Порядок в табе — по рангу.** Список разложен по ступеням: Покровитель →
  Меценат → Хранитель → Следопыт → Странник → без ранга. Внутри одной ступени
  выше тот, у кого больше стажа; у кого стажа ещё нет — в конце своей группы.
- **Как это сделано.** Клиент Minecraft сортирует ники по имени команды
  scoreboard, поэтому команда теперь кодирует два признака сразу:
  `!rk-a00` — Покровитель с высшим званием, `!rk-b07` — Меценат со средним,
  `!rk-f99` — без ранга и без звания. Имя команды не длиннее семи символов,
  старые команды `!rk-a`…`!rk-z` снимаются автоматически.
- **Закреп остаётся выше всех.** `pinned-names` из ядра (`!chrdk-pin`) не
  конфликтует с сортировкой: закреплённый игрок забирается из команд модуля
  званий, чужие команды (LuckPerms, TAB) не трогаются.
- **`/labels` — у каждого свой ник.** Команда прячет и показывает три вещи:
  `rank` (название и знак донатного ранга), `badges` (метки аддонов: класс,
  гильдия, стример, звание кладоискателя) и `header` (шапка и подвал таба).
  `all`, `on`, `off`, `reset` — всё сразу; `/labels` без аргумента показывает
  состояние всех переключателей одной страницей.
- **Настройка личная и постоянная.** Лежит в
  `plugins/CHRDK_Core/labels.json`, ключ — ник без регистра, поэтому выбор
  переживает перезаход, перезапуск и смену UUID. Запись атомарная
  (`SafeJsonWriter`), битый файл не роняет плагин — возвращается «видно всё».
- **Скрытие ничего не отнимает.** Права, опыт, срок ранга, лимиты домов и
  приватов, `/hat` — всё остаётся. Это оформление, а не привилегия.
- **Обновление сразу.** После переключения таб перерисовывается всем онлайн:
  имя в списке общее, и спрятанный ранг исчезает у всех, а не только у автора
  настройки. «Только для себя» ванильный клиент не умеет — и мы это не изображаем.
- **`/labels` в навигации таба и в меню** (`/menu` → «Общество» → «Оформление
  ника»). Сервер, не правивший стоковое меню, получает кнопку автоматически:
  добавлен снимок `presentation-legacy-1.4.182.yml`.

## Права и настройки

- Право `chrdkregister.labels` (по умолчанию включено всем).
- Конфиг ядра не изменился: секция `tablist` работает как раньше, добавлены
  только пояснения. Прятать надписи игрок может сам, команды администратора
  для этого не нужны.
- CHRDK_Ranks: `ranks.sort-tab: true` (как было) теперь сортирует по паре
  «ранг → стаж». `false` по-прежнему полностью выключает раскладку — тогда
  порядок задают другие плагины.

## Тесты и документация

- `LabelPreferencesTest` — умолчания, независимость переключателей, перезаход,
  регистр ника, `all`/`reset`, битый файл, форма `labels.json`.
- `RankLadderTest` — команды для всех ступеней, границы уровней и приоритет
  ранга над стажем.
- `PresentationUpdateTest` — снимок меню 1.4.182 обновляется один раз и только
  добавляет кнопку `labels`; пользовательские пункты не подменяются.
- Вики: `wiki/ranks.md` (порядок в табе и раздел `/labels`), `wiki/commands.md`,
  `wiki/menu.md`. README — таблица команд, меню и раздел «Порядок в табе».
