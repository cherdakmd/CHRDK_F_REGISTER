# 1.4.275 — новости в беседу сообщества ВКонтакте

Публикация на стене заменена отправкой текста и выбранной игровой карточки в одну
беседу **от сообщества**, через GitHub Actions и community token. Не используется
Minecraft-плагин и не обходятся ограничения VK. Неудачная проверка стены кодом 27
не создала пост; старые журналы стены остаются нетронутыми.

## Настройка и проверка

- Новый режим `find_chat`: поиск единственной беседы по последнему сообщению
  `#chrdk-news-setup` от пользователя. Выводит только ботовый peer_id, без названий,
  участников и содержимого остальных чатов. Variables автоматически не меняет.
- Новая Variable `VK_NEWS_PEER_ID`: ID именно для бота. Номер из пользовательского
  адреса `sel=cNN` нельзя считать тем же ID.
- `check_connection`: проверяет выбранную беседу/право писать, чтение истории и
  получение адреса загрузки фото. Без загрузки, отправки и записи журнала.
- `test_post`: после preflight отправляет одно тестовое сообщение с PNG на версию
  и получателя. Все проверочные режимы — только вручную на main, `publish=false`,
  `kind=tip`, тег пустой. Тест не включает расписание.
- Сохраняются ежедневные 12:00/18:00 МСК и отдельные новости релизов, но
  **`VK_AUTOPUBLISH_ENABLED` остаётся false до успешного теста и решения владельца**.

## Надёжность и приватность

Журнал схемы 2 изолирован по группе+peer, не переиспользует подтверждения стены или
другой беседы. Сохраняются `prepared/posting/posted`, подтверждённая запись `posting`
до отправки, сверка маркера и блокировка при неизвестном результате. `random_id`
стабилен для ключа и получателя. История проверяет автора-сообщество, peer и целую
строку маркера; чужие копии не считаются доставкой. Нулевой ответ VK сверяется с
историей без повторной отправки; при отсутствии подтверждения — остановка.

Приватный `access_key` фото используется только при отправке в памяти и не попадает
в публичные Issues, логи или артефакты. После сбоя на стадии prepared допускается
повторная загрузка фото, но не слепая повторная отправка сообщения. Клиент разрешает
только методы сообщений и загрузки фото для сообщений, методы стены запрещены.

Сообщение можно переслать; для стены текст+картинка публикуются вручную. Это **не**
нативный репост записи стены. Живой доступ к конкретной беседе оценивается отдельно
по ручной проверке, а не объявляется успешным по офлайн-тестам.

Основной комплект: 22 JAR+памятка, Core API 33, игровой код/правила не меняются.
Minecraft и TradeMC не затрагиваются, релиз и установка не выполняются.
