# 1.4.276 — актуальные подсказки и сообщество CHERDAK

## В этом обновлении

- Обновлены **все 41 игровое автосообщение**: знакомство с сервером, безопасность,
  личный банк, подтверждения покупок, профессии, классы, кланы, приваты и ВКонтакте.
  Действующие команды, ограничения и важные предупреждения сохранены.
- Обновлены заголовки и подписи **всех 16 тем** карточек ВК. Выбранный игровой фон,
  расписание ежедневно 12:00/18:00 МСК, календарная ротация и ключи дублей сохранены.
- В CHRDK_VK добавлены `/новости` и `/news` в ЛС и подключённой беседе.
  Обновлена справка, личные уведомления о входе, подборе пароля и сроке ранга
  перенесены в `messages.yml`; служебный setup-маркер не уходит в игровой чат.
  Карточки Actions не замыкаются обратно в Minecraft через мост.
- Неработающий резервный `wall.get` с ключом сообщества **больше не вызывается**.
  Старый `wall.poll-minutes` игнорируется. Анонсы настоящих записей стены остаются
  через события `wall_post_new` Bots Long Poll. `/vkadmin sync` сверяет подписки
  и VK Donut, не стену. Автопостинг в беседу выполняет GitHub Actions, не плагин.
- Клиент модуля ВК не следует HTTP-редиректам с токеном/Long Poll key; сетевые
  ошибки и сырые ответы не выводятся в диагностику. `random_id` в messages.send
  ограничен положительным 31-битным диапазоном. Секреты не запрашиваются в чате.
- Стоковые тексты до 1.4.275 обновляются по точному совпадению, собственные
  переводы и расписания не перезаписываются. Привязки, бусты и журналы сохраняются.

## Для обновления с последнего опубликованного 1.4.269

Комплект также включает ранее завершённые изменения 270–275:
- Мирная дисциплина кланов: персональная ответственность нарушителя,10 инцидентов
  за 30 дней — личное исключение и клеймо на 7 дней; глава не исключается и не получает
  клеймо, но платит штраф. Подробности и админ-коррекция — в памятке 1.4.270.
- Сняты CHRDK_Lottery, CHRDK_Party и CHRDK_Referrals; CHRDK_Events снят ранее.
  Общие события Core/Bukkit, кланы и локальные группы охоты не удаляются.
- Новости и игровые карточки подготовлены для беседы сообщества через Actions,
  с отдельными проверками, долговечным журналом и защитой неопределённой отправки.
  Тестовая доставка в выбранную беседу подтверждена владельцем; конкретная
  релизная новость считается доставленной только после проверки её запуска.

## Состав и безопасная установка — отдельным действием

**22 JAR одной версии + ОБНОВЛЕНИЕ.txt** внутри `chrdk-plugins-1.4.276.zip`.
Опциональный **`chrdk-vk-1.4.276.jar`** (`CHRDK_VK`, Core API 33) приложен отдельно,
не входит в общий ZIP. Не смешивать версии. Purpur 26.3, Java 25.

**Выпуск не означает установку на сервер.** Minecraft-сервер, его файлы и TradeMC
этой работой не изменяются. Порядок backup/разбора старых выплат и снятых модулей
из 1.4.271 обязателен: архивировать данные приватно, не стирать playerdata,
квитанции, банковские журналы или ожидающие выплаты. После согласованной остановки
вручную удалить снятые JAR из `plugins/`, `plugins/update/` и staging хостинга,
проверяя `name` в plugin.yml. CHRDK_Queue и другие снятые модули не возвращать.

Настройки ВК не подменяются значениями GitHub Variables: токен и peer-id игрового
моста настраиваются отдельно, по умолчанию 0/пусто. Ключ в чат не присылать.
Автопостинг не включается изменением JAR: нужен `VK_AUTOPUBLISH_ENABLED=true`
в Variables репозитория. Если флаг false, релизная отправка будет пропущена.
