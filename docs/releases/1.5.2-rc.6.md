стабильного `v1.5.2`, пререлизы `v1.5.2-rc.1`…`rc.4`, отдельный

## Что вошло

### Стена сообщества ВКонтакте: plugin-owned дайджест и пять постов в сутки

* **Суточный дайджест на стене** (`2290aa84`, `803270ce`). Весь контур живёт в
  плагине на сервере: сбор игровых событий, агрегация суток, постер 1280×720
  через Java2D (шрифт и фон внутри JAR), публикация в 21:00 `Europe/Moscow`.
  Ни GitHub Actions, ни внешний ledger, ни Issues Ledger в рантайме не нужны.
  Дедуп после рестарта — локальный `wall-digest.json`, `guid=chrdk-wall-<дата>`,
  маркер `#chrdk_<хеш дня>`, не более трёх попыток при сбое VK. Есть запасная
  строка «тихого дня» и в тексте поста.
* **Три метрики дайджеста** (`645e5908`): «Добыто блоков», «Получено алмазов»
  (`EntityPickupItemEvent` игрока с `Material.DIAMOND`), «Побед над монстрами»
  (`EntityDeathEvent` с `Monster` и живым `killer`). Бейдж «ИТОГИ ДНЯ» с датой
  ниже (`TITLE_BASELINE=236`), адаптивная вёрстка под длинные имена лидеров
  (`c7b4b76c`).
* **Ровно пять постов в сутки** (`d58ba1be`): 09:00 «САМЫЙ БОГАТЫЙ»,
  12:00 «САМЫЙ ПРОКАЧАННЫЙ», 15:00 «ШАХТЁР ДНЯ», 18:00 «ОХОТНИК ДНЯ» и
  21:00 обезличенный дайджест. Ники публикуются **и на картинке, и в тексте**
  четырёх карточек; вечерний дайджест по умолчанию остаётся обезличенным.
  Свои `guid=chrdk-card-<номинация>-<дата>`, ledger `daily-cards.json`,
  окно повторов пять минут, `MAX_ATTEMPTS=3`.
* Примеры постеров — `docs/vk-wall-digest/` (`e7e25b7a`, `f39b6442`,
  `d981ff9f`).

### Магазин

* **Русские имена и описания кастомных книг в `/shop`** (`645e5908`).
  Офлайн-каталог `ShopBookInfo` из `messages.yml`: 76 ID, 15 проклятий,
  «✦ Книга чар: <имя> <roman>» / «☠ Книга проклятия: …». Идентичность сделки
  и скупки по-прежнему сверяется по PDC/`book_key`/уровню, а не по
  `displayName`; `ShopConfig.ShopItem.label()`, публичный API и
  `API_VERSION=42` не менялись.

### Кузня тир-предметов и чары массовой добычи

* **«Карьер» ↔ чары megamine** (`79987bf5`). Легендарное тир-свойство
  `quarry` (`Effect.ZONE_BREAK`) больше не уживается на одном инструменте с
  `veinminer`/`excavator`. Мягкая двусторонняя совместимость: `ForgeMiningCompat`
  читает `tier_properties` по имени ключа из PDC, `MiningCompatPolicy` —
  `custom_enchants`; жёсткой зависимости `CHRDK_Enchants` ↔ `CHRDK_TierForge`
  и правок Core API нет. Guards стоят во всех путях записи: чары, ролл свойств,
  материалы, наковальня, меню улучшений.
* **«Забойщик» приравнен к колонне** (`548b8a48`). Отдельный PDC-механизм
  `up_hewer`, а не тир-свойство: `hasColumnMining` видит и `quarry`, и `hewer`.
  Снять улучшение можно даже при megamine; при добыче приоритет остаётся у
  колонны. Ранее выданные предметы не мигрируются.
* **`hewer` + `quarry` на одном инструменте разрешены** — запрещается только
  каждая колонна с чарами `veinminer`/`excavator`.

### `/vkadmin testpost`

* Новая команда `/vkadmin testpost [chat|wall|both] [текст]` с правом
  `chrdkvk.admin` (`548b8a48`). По умолчанию `both`, текст до 1000 символов,
  `guid=chrdk-test-<UUID>`, маркер `#chrdk_test_<8 hex>`. Тестовая запись идёт
  **только текстом** — без постера, без `photos.*`, не пишет в
  `wall-digest.json`/`daily-cards.json` и не двигает `last_announced_post_id`:
  маркер отсекается в `VkService.eligibleWallPost`. Прежняя `/vkadmin testchat`
  сохранена. Команда ничего не публикует сама: живой `wall.post` будет только
  когда администратор выполнит её на сервере.

### Баланс престижей

* **`PrestigeXpGate`** (`6ea8837`). Майнинг дешевле остальных, поэтому ступень
  **любого** навыка не может опережать минимальную ступень среди включённых
  навыков больше чем на `prestige.balance.max-lead` (по умолчанию `0`). Пока
  отрыв больше, опыт такому навыку не начисляется; отстающие качаются как
  обычно, игрок раз в минуту видит подсказку. Ступени и накопленный опыт не
  отнимаются, выровняться можно через `/skills prestige all`. Правило общее —
  иначе дешёвая прокачка переехала бы на рыбалку. Ключи
  `prestige.balance.enabled/max-lead/notice-seconds` читаются с дефолтами,
  bump схемы конфига не требуется. Админская выдача XP и физический дроп
  алмазов под блокировку не попадают.
