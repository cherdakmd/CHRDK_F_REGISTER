# CHRDK DiamondShop 2.0.2-rc.3

**Пререлиз только `CHRDK_DiamondShop`.** Исправлены переходы из главного меню
магазина, включая кнопку «Книги чар: наши». Общий ZIP и остальные JAR не публикуются.

## Причина

Перед отложенным открытием раздела GUI сравнивал Java-объект `Inventory` через `==`.
Purpur может вернуть новый wrapper для того же открытого инвентаря; проверка тогда
ошибочно считала меню закрытым и молча отменяла переход. В `latest.log` исключения
не требовались и не появлялись.

## Исправление

Проверка теперь сравнивает стабильный `InventoryHolder` нашего GUI. Она применяется
к разделам, вкладкам, возврату на главную и открытию количества товара. Если игрок
успел открыть постороннее меню, отложенный переход по-прежнему отменяется.

Экономика, цены, сделки, WAL и recovery не изменяются. Зелья остаются полностью
убранными из магазина, как в RC2.

## Установка и проверка

Остановить сервер, сохранить backup и заменить только DiamondShop на
`chrdk-diamond-shop-2.0.2-rc.3.jar`. Остальные плагины остаются 2.0.1. Вайп не нужен.

После запуска открыть `/shop`, нажать «Книги чар: наши» и убедиться, что открывается
каталог книг. Затем проверить возврат на главную и открытие другого раздела.
