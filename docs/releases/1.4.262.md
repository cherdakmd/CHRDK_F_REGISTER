# 1.4.262 — интеграция ВКонтакте (`CHRDK_VK`) и мосты Core API 32

## Принятые правила

Добавлен самостоятельный аддон **`CHRDK_VK`** (`chrdk-vk-1.4.262.jar`), работающий
поверх официального VK Bots Long Poll API (`api.vk.com`, v5.199) и мостов
**`CHRDK_Core` API 32**:

- привязка игрового аккаунта к профилю ВКонтакте по одноразовому коду `/vk link`
  в личных сообщениях сообщества (`https://vk.ru/chrdk_reborn`), отвязка через
  `/vk unlink` или `/отвязать`, лимит по умолчанию — 1 игровой аккаунт на 1 `vk_user_id`;
- уведомления в личные сообщения ВК о входах в аккаунт (`/vk notify` / `/уведомления`),
  о попытках подбора пароля и о скором окончании срока донатного ранга;
- экстренные команды самозащиты из ВК: `/выход` (сброс IP-сессий и завершение
  текущего сеанса онлайн) и `/заморозить` / `/разморозить` (блокировка входа в
  аккаунт в `RegistrationStore` с сохранением после рестарта);
- **пароли и секреты TOTP через ВКонтакте никогда не меняются и не сбрасываются**;
- двусторонний мост между глобальным чатом сервера и беседой сообщества ВКонтакте
  (`/chatid` в беседе + `/vkadmin setchat <peer_id>` и `/vkadmin testchat` на сервере)
  с проверкой привязки аккаунта, серверного `/mute`, заморозки входа, `/ignore`,
  фильтра слов и защитой от массовых пингов `@all`/`@online`;
- косметическая метка `vk` в `/labels` (`[ВК]` / `[VK Donut]`), однократные
  игровые XP-бусты за первую привязку и подписку на сообщество (с защитой от
  повторного получения при перепривязке), бонус времени покупок каталога для
  активных подписчиков **VK Donut** (через `ShopBonusProvider`, без сложения с
  другими подписками и в рамках потолка бонуса) и автоанонсы новых постов стены.

При пустом токене сообщества `CHRDK_VK` запускается в безопасном автономном
режиме без сетевых запросов.

## Миграция и установка

Полный комплект **26 JAR 1.4.262 + ОБНОВЛЕНИЕ.txt**. Core API **32**, bank schema 8,
Guilds schema 3, Classes schema 4. Стоковое меню 1.4.261 мигрирует с сохранением
резервной копии; пользовательские меню и тексты не перезаписываются.

Первый переход с комплекта из 25 JAR выполняется вручную при штатно остановленном
сервере и после полного согласованного backup миров, `playerdata`, конфигов и
данных плагинов (старый обновлятор 1.4.261 ожидал 25 JAR). Не использовать `/reload`.
