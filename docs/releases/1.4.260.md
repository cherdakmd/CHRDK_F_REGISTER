# 1.4.260 — меню клана и цветной клан в TAB

- `/clan gui`, `/clans gui`, `/guild gui` и остальные алиасы открывают существующее
  меню: состав, роли, казна, войны, личные приваты и мирный режим. `/clan menu`
  и `/clan` без аргументов продолжают работать. `gui` есть в автодополнении.
- Клан в стандартном TAB: **красный — боевой**, **зелёный — мирный**. ☮ означает
  активную мирную защиту; ⌛ — её подготовку. Цвет режима сам по себе не обещает
  немедленной защиты. Пустой тег заменяется названием; без клана нет скобок.
- Это отдельный статус PvP вне платных/косметических мест `/labels`, без ранга,
  с удалением дубликата в TAB. Назначения мест, скрытие и сборка чата не меняются.
  `chat-prefix: false` не прячет статус TAB. Отключение Guilds снимает провайдера.
- Переключение режима, переименование/смена тега и выход/роспуск подхватываются
  следующим обновлением TAB (обычно 2 секунды), без перелога. Предвходовый игрок
  не получает клановую метку. Меню сохраняет проверки входа, прав и enabled.
- Знамя и кнопка режима в GUI используют красный/зелёный цвет и текст режима.
- Пустой формат TAB по-прежнему не меняет имя и не конфликтует с внешним TAB;
  пользовательскому формату нужен `%player_tagged%`. Новые тексты добавляются
  через стандартный Messages.load, старые сообщения/конфиг не перезаписываются.

Экономика, PvP-правила и сохранения 1.4.259 не изменены. Core API 31, bank schema 8,
Guilds schema 2 и Classes schema 4 остаются прежними. Обновлять полный комплект
**25 JAR 1.4.260 + ОБНОВЛЕНИЕ.txt** после остановки и согласованного backup,
без `/reload`. Сервер автоматически не обновляется; TradeMC не изменяется.
Minecraft smoke-test остаётся отдельной проверкой после установки.
