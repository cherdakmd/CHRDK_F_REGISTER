# CHRDK Fishing Horizons 2.0.26-rc.61 — предварительный выпуск

**Экспериментальный комплект, не стабильный релиз.** Для Purpur 26.3 / Java 25;
собран из `d012ed78caa37a5ecd82f379a41f177ab9bcd994`. [Проверки кандидата](https://github.com/cherdakmd/CHRDK_F_REGISTER/actions/runs/46067235450)
прошли, включая тесты однократного обновления конфигов; аварийные испытания
восстановления отложены, работа на реальном сервере и в клиенте не проверена.

## Однократное включение оформления

Для активации сначала установите общий совместимый пак, остановите сервер и
создайте полную согласованную резервную копию. Затем создайте пустой файл
`plugins/CHRDK_Core/enable-chrdk-textures-once` без расширения. При следующем
запуске модули однократно включат подготовленные настройки текстур **в том числе
явно выключенные ранее**. Это не произойдёт без указанного файла. У каждого
модуля создаётся `config-before-chrdk-textures-rc61.yml` и в его конфиге
записывается маркер. После миграции последующие изменения настроек владельца
сохраняются. При ошибке модуля настройки этого модуля не подтверждены —
проверьте журнал; другие модули могут быть обновлены. После успешного запуска
всех нужных модулей удалите файл активации, чтобы не включать настройки у тех,
что будут добавлены позже. Подробности: `TEXTURE-OPT-IN.md` внутри комплекта.

Старые предметы не переоформляются автоматически; изменения касаются новых
предметов, включая новые книги торговли/стола и добычи, и подготовленных меню.
Пользовательские варианты, сторонние плагины и ванильные интерфейсы не входят в
полное покрытие. Собственный пак нужно сохранить и объединить, а не затирать.

## Fishing и установка

RC.61 содержит изменение RC.60 для возможной причины `SQLITE_CANTOPEN` при
миграции журнала: временные данные миграции SQLite размещаются в памяти, WAL,
FULL sync и финансовые защиты остаются. Причина ошибки на конкретном хостинге
не доказана, исправление не гарантировано; миграция требует дополнительной памяти.

`chrdk-closed-server-2.0.26-rc.61.zip` — полный комплект CHRDK и инструкции;
`chrdk-resource-pack-2.0.26-rc.61.zip` — общий пак отдельно. Сторонние плагины
не входят. Локальный `plugins/CHRDK_CustomItems/custom-items-pack.zip` автоматически
не перезаписывается. Параметры URL и хеша должны соответствовать отданному паку.

До установки остановите сервер и сохраните миры, playerdata, банк, конфиги и
все `plugins/CHRDK_*`, включая ключи, SQLite и WAL/SHM при наличии. Не использовать
`/reload`; не удалять базы и маркеры. Журнал продаж мигрирует на schema 5, которую
старый Fishing JAR не поддерживает; не откатывать отдельно JAR, журнал или банк.
Не проводить аварийные/дюп-тесты на production. Садок не реализован, подпись не
предотвращает копирование удочек; клиентская проверка и полное покрытие предметов
остаются незавершёнными.
