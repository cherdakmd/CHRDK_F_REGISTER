# CHRDK 2.0.18 — Вырезка тиров и кузни

> **Статус: ВЫПУЩЕНО — модуль тиров и кузни полностью вырезан, комплект стал легче на JAR.**
> Плюс новый датапак «Сокровища Бесплодных земель» поверх Mine Treasure
> и четыре production-исправления.

## Тиры и кузня вырезаны

Модуль тиров и кузни (`CHRDK_TierForge`) полностью вырезан из сборки и
прекращает разработку. Из игры убрано всё его оформление: пункт «Редкости
снаряжения» с подсказкой о тирах крафта из меню сервера, раздел «Кузня» из
магазина (магазин больше не продаёт и не скупает кованые предметы; купленные
ранее остаются у игроков), дневная карточка «Мастер тиров» из ВКонтакте
(дневные карточки теперь на 7 номинаций), ярлык «Титул кузни» и подсказки о
командах тиров. Публичный API ковки снят, версия API — 46.

**С данными ничего не происходит** — вайп не требуется. При обновлении со
старых версий удалите из `plugins/` JAR модуля тиров и кузни
(`chrdk-tier-forge-*.jar`) — в комплект он больше не входит.

## CHRDK Treasure Addon 1.0 — сокровища Бесплодных земель

Отдельный датапак поверх Mine Treasure: новые предметы с способностями из
добычи камня, без единого конфликта с самим Mine Treasure (только свои пути
`data/chrdk_treasure/*`). Шесть сокровищ: Счастливая монета и Тяжёлая перчатка
(обычные, атрибуты), Пружинные сапоги и Дымовая шашка (редкие), Крыло Феникса
и Звёздный ключ (легендарные, срабатывают по правой кнопке на блоке). Шансы —
2 % / 0,5 % / 0,1 % за проломленный блок. Предметы помечены своей меткой, и
перки CHRDK не дублируют награды Mine Treasure. ZIP пака — отдельный ассет
релиза, кладётся в `datapacks/` сервера рядом с Mine Treasure.

## Генератор: улучшения снова покупаются

Покупка улучшений генератора отклонялась банком: источник `generator-upgrades`
не входил в его белый список. Источник возвращён — улучшения снова покупаются
за деньги.

## Точило: спиливает все чары, включая проклятия

Точило снимает с книги абсолютно все чары — включая проклятия — и оставляет
чистую ванильную книгу.

## Скиллы: прокачка и отклики кристалла в акшнбаре

Прибавка опыта и ответы кристалла опыта показываются в акшнбаре над хотбаром:
чат больше не спамится каждым применением.

## Мелкие исправления

Миграция текстов v12 вычищает застрявший плейсхолдер `%left%` в сообщении
`xp-potion-used`.

## Что снять с обновления

JAR модуля тиров и кузни (`chrdk-tier-forge-*.jar`) в комплект не входит —
удалите его из `plugins/`. Ранее снятые `chrdk-pets` и `chrdk-orders` тоже не
входят в комплект. `chrdk-disasters` больше не прикрепляется к релизам.

## Обновление

Обычное: комплект **18 JAR одной версии** в общем ZIP, `chrdk-vk-2.0.18.jar`
отдельно, Mine Treasure не трогать. Положить JAR-ы в `plugins/` и
перезапустить сервер: данные игроков не трогаются, вайп не требуется.
