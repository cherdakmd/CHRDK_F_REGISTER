# 1.4.273 — советы и напоминания дважды в день

- Вместо среды/воскресенья: **ежедневно в 12:00 и 18:00 по Москве**.
  GitHub Actions cron — `0 9,15 * * *` UTC. Новости релизов выходят отдельно.
- 16 тем последовательно чередуются за 8 дней, две разные темы в сутки.
- Полуденный ключ `tip:YYYY-MM-DD:12` не блокирует вечерний `tip:YYYY-MM-DD`.
  Вечерний ключ оставлен прежним: старый журнал и уже опубликованные записи
  не сбрасываются и не переиздаются после обновления.
- Допустима задержка менее 6 часов; выбирается только последний актуальный
  слот. Ночью и перед полуднем устаревшие посты не отправляются. Пропущенные
  публикации не догоняются пачкой. Cron GitHub не гарантирует точную минуту.
- PNG-карточки и безопасный режим превью сохранены, как и все предохранители
  отправки: отдельный токен, включающая переменная, main, постоянный журнал.

Регрессии проверяют все дни недели, границы окон, UTC/Москву, отдельные ключи
и однократную отправку обоих слотов с перезапуском журнала.
Основной комплект — 22 JAR, Core API33; игровых изменений нет.
Реальная отправка, подключение VK, выпуск релиза и установка на сервер не выполнялись.
