**Экспериментальный кандидат, не стабильный релиз.** Собран для Purpur 26.3 /

## Предпросмотр наковальни

Когда объединение ванильных чар даёт уровень выше ванильного максимума, после
обработчиков обновляется текущий открытый инвентарь игрока на следующем тике.
Это направлено на расхождение предварительного результата и полученного
предмета; **на конкретном сервере исправление пока не проверено**. Логика уровней,
цена, списание и данные предмета этим обновлением не изменяются. Проверки на
искусственных данных охватывают одно обновление на несколько событий, закрытие
окна и выход игрока, но не заменяют тест реального Purpur-клиента.

`chrdk-enchants-2.0.26-rc.62.jar` — отдельный аддон для установки поверх
совместимого комплекта RC.61 с его Core; для этого изменения другие JAR и пак
переставлять не требуется. `chrdk-closed-server-2.0.26-rc.62.zip` — полный
комплект, `chrdk-resource-pack-2.0.26-rc.62.zip` — общий пак. Проверка суммы:
`SHA256SUMS.txt`. Перед заменой остановите сервер и сохраните резервную копию;
старый JAR уберите из `plugins`, не оставляйте две версии. Не используйте `/reload`.

## Ограничения

- Предметы и их операции не воспроизводились на сервере пользователя. При
  проверке сравните отображение в результате с фактически полученным предметом;
  не проводить дюп- или аварийные испытания на рабочем сервере.
- Fishing содержит смягчение возможной причины `SQLITE_CANTOPEN` из RC.60;
  причины ошибок конкретного хостинга не всегда установлены. Старая схема журнала
  мигрирует до schema 5, которую старые JAR не поддерживают. Не откатывайте
  по отдельности JAR, журнал или банк, не удаляйте базы и ключи.
- Общий ресурс-пак не заменяет автоматически существующий файл и не включает
  оформление сам. RC.61+ поддерживает явную однократную миграцию настроек; см.
  `TEXTURE-OPT-IN.md` в комплекте. Старые предметы не переоформляются.
- Аварийное восстановление и клиентское покрытие всех предметов не подтверждены;
  автоматический садок не реализован, подпись не предотвращает копии удочек.
  Перед обновлениями нужны согласованные бекапы мира, playerdata и всех плагинов.
