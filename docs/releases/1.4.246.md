# 1.4.246 — справочник с нуля и единый проверяемый деплой

26 плагинов, Core API 27, Purpur 26.3 / Java 25.
Это переработка документации и CI, **не изменение игровых механик**.

## Для игроков

- Все 36 страниц написаны заново, восемь групп: начало, мир, экономика,
  развитие, снаряжение, ранги, общение и справка.
- Отдельные страницы общих целей, игровых званий, обновлений и источников.
- Главная с маршрутами действий, мобильная навигация, тёмная/светлая тема,
  полный поиск Ctrl-K, копирование команд, оглавление и соседние страницы.
- Полные каталоги: 178 товаров и 76 чар, таблицы рангов/покупок, лимитов,
  ежедневок и команд формируются из конфигов и реестров.
- Явно различены `/bal`, коллективные казны и ресурсы охоты, платные ранги и
  игровой XP-буст. Регистрация, пароль и добровольная TOTP 2FA сохраняются.
- Профессия описывается через `/profession`, профиль через `/profile`:
  неоднозначный `/prof` не рекламируется. Сам конфликт алиаса здесь не исправлен.
- Версия/commit/дата относятся к исходникам; это не мониторинг живого сервера.

## Чтобы сайт не отставал от кода

- Каждая страница связана с модулями через `review`. Изменение исходников,
  ресурсов или текста требует явной повторной сверки с причиной в `reviewed.json`.
  Добавленный модуль без документации блокирует проверку.
- Публичные данные берутся только по whitelist. Полные конфиги, секреты и команды
  доставки не попадают в HTML. Каталог чар проверяет совпадение Java-реестра и конфига.
- Один `build.yml` на каждый push в `main`/`arena/**` и все PR, **без фильтров путей**.
  Pages ждёт успешной полной Java-сборки и проверок вики. Ветки и PR не публикуют сайт.
- Release также проверяет актуальность документации. Каноническая версия сайта —
  `main`, а не произвольно выбранный тег. Ошибка проверки не заменяет работающий сайт.
- Регрессии Python/Node, браузерные проверки 36 страниц на компьютере и телефоне,
  поиск/ошибки сети/фокус/копирование/no-JS и автоматические axe-проверки основных
  страниц в двух темах. Это не полная ручная сертификация WCAG и не игровой smoke-тест.

## Публикация и установка

Для обновления **сайта** достаточно merge проверенного PR и успешного Pages job.
Публикация сайта не устанавливает плагины, не создаёт тег и не выпускает ZIP.

Если отдельно выпускается комплект этой версии, сохраняется единый
`chrdk-plugins-1.4.246.zip`: 26 JAR и `ОБНОВЛЕНИЕ.txt`, без отдельных JAR-assets.
Игровая установка для обновления вики не требуется. При отдельном обновлении
плагинов сохраняются backup, штатная остановка и [инструкции перехода 1.4.245](1.4.245.md).
Не удалять данные и не применять `/reload`.

Снятые Events/Streams/Bosses/Treasures не возвращаются. TradeMC материалы не
подготавливались и не публиковались. Проверяющий инструмент сохраняет версию
существующего комплекта при одном только bump плагинов, но по-прежнему строго
сравнивает товары, тексты, цены, сроки и хеши изображений с каталогом. F03–F12 из [общего аудита](../audits/full-project-1.4.242.md)
остаются открытыми. Проверка актуальности — повод для ручной сверки, не доказательство
правильности всей прозы, финансового восстановления или отсутствия ошибок сервера.

Порядок дальнейшего сопровождения — [docs/WIKI.md](../WIKI.md).
