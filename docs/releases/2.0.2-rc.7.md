# CHRDK Core 2.0.2-rc.7

**Пререлиз только `CHRDK_Core`.** Исправлен запуск платных телепортов после
согласованного обнуления банка. Claims этот JAR не изменяет.

## Безопасное восстановление PaidActions

После reset банк мог сохранить источник `teleports`/`claim-teleports` с прежним
lineage, а локальный `paid-actions.json` содержал другой UUID. Из-за этого `/rtp`,
платные дома и связанные услуги оставались в состоянии сверки даже без платежей.

Теперь при старте PaidActions принимает lineage, уже закреплённый банком, только
при одновременном выполнении условий:

- journal и source исправны;
- нет pending payment;
- sequence журнала равен 1;
- нет READY/EXECUTING действий;
- нет возвратов и ручных resolutions.

Дома и остальные значения `values` сохраняются. При любом финансовом обязательстве
автоматическая смена lineage запрещена: прежняя fail-closed блокировка остаётся,
данные не удаляются и повторная эмиссия невозможна.

## Установка

Остановить сервер, сохранить backup и заменить только Core на
`chrdk-core-2.0.2-rc.7.jar`. Остальные плагины и DiamondShop RC6 не меняются.

`bank.json`, `paid-actions.json`, `bank-charge.json`, дома и playerdata сохраняются;
вайп не требуется. После запуска проверить `/rtp` дважды: первая оплата должна пройти,
повторная команда не должна зависать на старой сверке.
