# 1.4.191 — конкретные места надписей, без автоподмены

Продолжение оформления 1.4.190. По решению владельца выбран принцип
**«конкретные места»**, а не автоматическое заполнение по приоритету.

- `/labels`: средний ряд — места после ника. ЛКМ открывает выбор полученной
  надписи, ПКМ оставляет место пустым. Закрытые места показывают ступень
  доступа, рассчитанную из `labels.display.slots`; не открываемые конфигом
  места явно отмечены. В шапке — число реально показанных надписей, а не
  число включённых источников. Ниже — отдельные переключатели источников, включая
  шапку TAB, которая по-прежнему вне лимита. Цвет и пресеты — отдельные кнопки.
- Выбор показывает реальный текст метки и доступность. Выбирается только
  полученная/доступная надпись; её источник при выборе включается. Повторный
  выбор переносит источник с другого места, а не создаёт дубликат.
- Истёкший ранг, скрытая метка, выход из гильдии или недоступный аддон не
  запускают подмену. Место временно пустует, выбор сохраняется. При понижении
  ранга содержимое лишних мест сохраняется; при восстановлении лимита оно
  возвращается. Очищенные места не заполняются сами, даже после «Включить
  источники». Знак с названием ранга по-прежнему одна надпись после ника.
- `/labels order` теперь обзор мест, а не очередь приоритетов. ЛКМ выбор,
  ПКМ очистка; «Обычные места» сбрасывает только назначения. Старая команда
  `order <метка> left|right` перемещает между соседними открытыми местами;
  ответ показывает настоящий номер места, даже если перед ним есть пустота.
- Статусы: видно / скрыто / получено, но не выбрано / не получено или источник
  недоступен / сохранено на закрытом месте. Сводки `/profile` и `/labels status`
  используют ту же сборку. TAB, чат и превью не заполняют места по-разному.
- `labels.json` версии **4**: добавлен `slots` — восемь назначений по позициям,
  пустая строка означает намеренно свободное место. Пресеты сохраняют эти
  назначения, включая полностью пустой вид. Неизвестные источники, дубликаты
  и неверные значения превращаются в пустые позиции, а не сдвигают список.
  Источники, цвет, покупки и прежние пресеты не удаляются.
- Назначение места и включение источника сохраняются одним изменением
  состояния. Повторно проверяются лимит и доступность при выборе, включая
  клик из окна, открытого до истечения ранга или перезагрузки конфигурации.
  В обоих меню повторно проверяется право; shift/цифровые/служебные клики
  не меняют оформление. Shift+ПКМ удаления пресета сохранён.
- Лимиты надписей **2/2/2/3/4/5**, лимиты пресетов, платность премиум-цветов,
  права, экономика и прогресс не менялись. Исправление подписи цвета 1.4.190
  сохранено. Русские тексты, README, вики и регрессионные тесты обновлены.

## Совместимость и обновление

1. Сохранить резервную копию `plugins/` и мира перед заменой JAR. Не удалять
   `plugins/CHRDK_Core/labels.json`, покупки и профили.
2. Файлы и пресеты версий 1–3 читаются без ручной миграции. Если `slots` ещё
   нет, старый порядок считается фиксированными назначениями. Неполученная
   надпись в начале списка не пропускается ради следующей. После первого
   выбора места сохраняются явно в формате 4.
3. Без личных настроек стандартные назначения: ранг, класс, гильдия,
   кладоискатель, кузня, стример, квесты, достижения. Если ранга нет, его место
   пустует; игрок может вручную выбрать вместо него полученную надпись.
4. Обновить секцию `labels` своего `messages.yml` по ресурсу нового JAR:
   старые собственные тексты о «приоритете» имеют преимущество над новыми.
   Новые ключи берутся из ресурса, весь файл удалять не нужно.
5. Лимит задаётся прежним `labels.display.slots`, пресеты — отдельным
   `labels.presets.slots`. Изменения конфига применяются через `/pass reload`.
6. Не откатывать на старый JAR с рабочим файлом версии 4: он не знает поле
   `slots` и может потерять назначения при записи. Для отката использовать
   сделанную перед обновлением резервную копию.

## Проверки

Тесты: пустые места и полностью пустой пресет после рестарта; сохранение
цвета/переключателей; отсутствие подмены при исчезновении источника и
истечении ранга; возврат закрытых мест; перенос без дубликатов; недоступные
источники и клики из устаревшего окна; старые файлы/пресеты; неверные данные
без сдвига позиций; независимые лимиты; раскладка мест без пересечения кнопок.

Проверки репозитория: полная Gradle-сборка с тестами ядра и всех модулей на
Java 25, контракт сообщений всех модулей, 9 Python-тестов проверки архива,
101 YAML-файл и вики (36 страниц, ссылки и навигация).

На копии сервера проверить: `/labels`, выбор/очистку, `/labels order`,
`/labels preset`, `/profile`, `/menu`; обычного игрока и I–V, смену класса,
выход из гильдии, истечение ранга, `/pass reload` со снижением лимита при
открытом выборе, рестарт и общий вид с другого клиента. Проверить также
shift/цифровые клики, drag, отзыв права и премиум-цвет без покупки.
Minecraft/Purpur в песочнице не запускается; юнит-тесты не заменяют игровой тест.

Тег и GitHub-релиз — только по отдельной команде владельца.
