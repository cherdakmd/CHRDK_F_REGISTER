# 1.4.272 — автоматические новости и полезные посты ВКонтакте

Подготовлен отдельный GitHub Actions-публикующий процесс, не игровой бот и
не изменение доступа к Minecraft. Игровые правила/цены/данные не меняются.
Основной комплект по-прежнему **22 JAR + ОБНОВЛЕНИЕ.txt**, Core API33.
Опциональный CHRDK_VK остаётся отдельной сборкой, его методы/токен не меняются.

- Новости — после успешного Release и появления ZIP; текст из отдельной
  проверенной заметки игрокам в самом теге, не из технического changelog.
- Советы, возможности, напоминания — среда/воскресенье в 18:00 по Москве.
  16 тем, точные выдержки вики и публичные поля конфигов, без выдуманных чисел.
- Простые PNG-карточки 1280×720 генерируются локально Pillow/DejaVu, без
  генеративного API и чужих изображений. CI проверяет все тексты и карточки.
- Постоянные месячные журналы в GitHub Issues, VK guid/маркер и сверка стены
  защищают от дублей после рестарта. Неоднозначная отправка блокирует новые
  посты до сверки, а не повторяется вслепую. Секреты и ответы API не логируются.
- По умолчанию **только превью**, реальный автопостинг выключен до настройки
  отдельного пользовательского VK-токена, ID группы и разрешающей Variable.
  Токен сообщества игрового CHRDK_VK для wall.post не подходит.
- Никакого обещания «обновление установлено»: выпуск ZIP отделён от установки.

[Подключение, пробный режим и восстановление](../automation/vk-publications.md).
Сборка и офлайн-тесты не заменяют проверку прав VK при подключении.
Релиз/публикации в VK/установка на сервер в этой задаче не выполняются.
