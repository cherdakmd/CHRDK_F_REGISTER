# 1.4.245 — строительная палитра и рецептурная экономика магазина

**26 плагинов**, Core API **27**, Purpur 26.3 / Java 25.
Игровой алмазный `/shop`; платный каталог и TradeMC не расширялись.

## Магазин: 142 → 178 товаров

Добавлены 36 готовых строительных материалов: все 16 цветов бетона, все 16 цветов
терракоты, гладкий камень, каменные кирпичи, полированный глубинный сланец и
кварцевые кирпичи. Шесть категорий, пять страниц «Все», две страницы «Блоков».
Ищите `/shop find concrete`, `/shop find terracotta`.

Все новые позиции **только для покупки игроком**: `sell-enabled: false`.
Ограничение проверяет сам торговый сервис, а не только GUI: команда продажи,
`all`, максимальная продажа и отложенное подтверждение не могут обойти запрет.
`/shop sellall` пропускает эти товары, не забирая предметы. Поиск, `/shop price`
и иконки явно показывают отсутствие обратной скупки. Старые товары без флага
сохраняют возможность продажи.

## Важное изменение выручки

Анализ выявил арбитраж между независимыми ценами: прежде 64 блока слизи за
192 алмаза можно было распаковать в 576 сгустков и продать за 504 при эталонных
запасах. Один спред 10 % и движение виртуального запаса этого не предотвращали.

Добавлен консервативный потолок скупки по проверенным рецептурным путям:
прессование/распаковка, мёд, глина/обжиг, плавка сырья, древесина/палки,
книги/полки, рельсы, редстоун-механизмы, отдельная еда и другие цепочки.
Учитываются промежуточные материалы вне магазина. Расчёт идёт от **нижних границ
покупки из конфига**, чтобы крупная покупка не могла сама повысить потолок
последующей продажи. Труд и топливо не добавляются к безопасной нижней оценке.

**Скупка некоторых ресурсов и изделий стала значительно ниже прежней.**
Например, при стандартных настройках и эталонных запасах те же 576 сгустков дают
36 алмазов. Динамический график mid-цены не обещает такую же выручку.
Размер эталонной партии тоже мог измениться. Перед продажей — `/shop price`;
сумма в подтверждении окончательная, аргумент количества по-прежнему означает штуки.
Выплат за ноль нет; покупка округляется вверх, продажа вниз, расчёты целыми алмазами.

Это защита **явно проверенных цепочек**, а не утверждение о полном отсутствии
арбитража во всех рецептах Minecraft, внешних магазинах, фермах и модификациях.
Полный анализ, границы проверки и все 178 позиций — [в каталоге](../SHOP_CATALOG.md).

## Общий баланс, меню, TAB и сайт вики

- Оплата по-прежнему сначала с `/bal`, недостача физическими алмазными предметами;
  сдача и выручка на личный счёт. Казны остаются отдельными. Новой валюты нет.
- В `/menu` и объявлениях убрана неверная подпись об отдельном кошельке.
  Есть подсказка о количестве и строительном декоре без обратной скупки.
- Навигация TAB добавляет `/bal` при наличии права и `/shop` при включённом
  аддоне и праве использования. До полного входа игровые ссылки скрыты.
- Обновлены страница магазина, экономика, меню и главная сайта из `tools/wiki`.
  Деплой GitHub Pages по существующему workflow выполняется только из `main`;
  тег плагинов сам по себе сайт не публикует.

## Обновление существующей установки

1. Закрыть вход игрокам, сделать согласованный backup мира, playerdata,
   конфигов, данных ядра/аддонов и финансовых журналов. Штатно остановить сервер.
2. При переходе со старого обновлятора **≤ 1.4.243 — первый раз вручную**:
   старый код не умеет принять этот ZIP-only релиз; [подробности 1.4.244](1.4.244.md).
3. При переходе с опубликованной 1.4.238 сначала выполнить инструкции снятия
   [Bosses/Treasures](1.4.239.md), [Streams](1.4.241.md) и [Events](1.4.242.md),
   включая сверку неоднозначных выплат. Снятые JAR и их дубли убрать; данные архивировать.
4. Установить 26 JAR **одной версии** из ZIP. Не удалять банк, `shop-data.json`,
   учётные записи и журнал восстановления. Не использовать `/reload`.
5. При запуске **точно стоковые** 142 строки автоматически обновятся до 178:
   сначала создаётся `config-before-catalog-1.4.245-*.yml`, затем атомарно меняется
   только `items`. Пользовательские валюта, спред, лимиты и прочие настройки сохраняются.
   Правленый/сокращённый/пустой каталог не подменяется: при необходимости вручную
   перенести нужные новые строки из `config.yml` JAR. Ограничения рецептурной
   скупки действуют и на известные материалы пользовательского каталога.
6. Стоковые меню/объявления/TAB мигрируют с резервной копией; персональные списки
   не заменяются. Проверить свои подписи и интеграции вручную.
7. После запуска проверить `/menu`, TAB, `/shop find concrete`, `/shop price slime_ball`,
   покупку 1 и 64 предметов, запрет продажи декора, `sellall`, `/bal` и журнал сервера.

Формат публикации: единственный `chrdk-plugins-1.4.245.zip`, внутри 26 JAR и
`ОБНОВЛЕНИЕ.txt`. Отдельных JAR-assets и донатных материалов нет. Установка на
сервер — отдельное действие; публикация её не выполняет.

## Проверки и ограничения

Добавлены регрессии размера/состава каталога, недеструктивной миграции,
запрета скупки декора в сервисе, положительных целых котировок при крайних
запасах и разных спредах, рецептурных путей при независимо изменённых запасах,
большой покупки с последующей распаковкой, глины, мёда и металлов.
Проверяются также миграция меню/TAB, сообщения, сайт и формат release ZIP.

Это не нагрузочный или игровой smoke-тест работающего сервера. Из общего
[аудита 1.4.242](../audits/full-project-1.4.242.md) ранее закрыты F01 и F02;
**F03–F12 не исправлялись этим обновлением**, в том числе риски хранения данных.
Не считать этот релиз завершением общего аудита. Регистрация, пароль и
добровольная TOTP 2FA сохраняются; Core API не меняется.
