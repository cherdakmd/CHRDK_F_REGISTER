# 1.5.7 — новый алмазный рынок

## Новый `/shop`

Старый `ShopGui` удалён. Теперь команда открывает главную витрину с девятью
тематическими разделами, общим каталогом, Кузней и зельями навыков, быстрой
продажей ресурсов, балансом, акцией дня и краткой справкой.

В разделах карточки показывают точные цены покупки и продажи, размер партии,
запас и тренд. ЛКМ выбирает покупку, ПКМ — продажу; количество указывается в
следующем окне. Доступны поиск `/shop find` и редактор `/shopadmin edit`.

Витрина использует суммы текущего minor-сервиса: 100 minor = 1 алмаз. Она не
создаёт собственный кошелёк и не рассчитывает платёк. Перед открытием количества
повторно сверяются сервис, товар, партия, ask и bid; устаревшая цена отклоняется.
Курс, тарифы, `/bal`, sellall, WAL, ShopJournal, `shop-data.json` и
`shop-overrides.json` не меняются. Новый GUI не снимает quarantine `pending`.

## Аукцион полностью снят

Удалены модуль `auction`, `/auction`, `/ah`, GUI, права, публичный API сделок,
пункты меню, автосообщения, Wiki и лоты из описаний платных рангов. Общий ZIP
теперь содержит **19 JAR**. Старые банковские поля остаются только для чтения
существующей schema/backup и не предоставляют аукцион.

Перед установкой на production снимите лоты, верните предметы и незавершённые
выплаты на старой версии и сделайте backup `CHRDK_Auction`. После полной остановки
удалите старые `CHRDK_Auction*.jar` из `plugins/` и `plugins/update/`, затем
установите новый комплект. Автоматической миграции или удаления лотов нет.

## Админские команды из игры

`ServerGuard` больше не игнорирует админскую группу LuckPerms: после успешного
`/login` и требуемой 2FA игрок с явным правом `chrdk.guard.trusted` может
выполнять корни из `security.console-only-commands`. Автонастройка `/pass
luckperms setup` включает это право в существующую группу `admin`; повторный
запуск идемпотентен и не выдаёт его `default` или `moderator`. Ручная альтернатива:
`/lp group admin permission set chrdk.guard.trusted true`. Группа с LuckPerms
`*` получает допуск автоматически. OP без права, обычные игроки и
неавторизованные сессии блокируются. Отдельные console-only проверки скачивания
обновлений не изменены.

## Обновление и проверка

Общий ZIP содержит 19 JAR версии 1.5.7 и памятку; VK, Disasters, Mine Treasure
и SHA256SUMS отдельно. Остановить сервер, сделать backup, заменить весь комплект
и полностью перезапустить. Не смешивать JAR разных версий.

Проверить главную и каждый раздел, возврат из количества, покупку/продажу по
дробной цене, недостаток средств/места, sellall, Кузню, поиск и права игрока.
После restart незавершённая сделка должна восстановиться ровно один раз;
quarantine нельзя обходить интерфейсом.
