# CHRDK DiamondShop 2.0.2-rc.2

**Пререлиз только `CHRDK_DiamondShop`.** Исправлена пустая отдельная витрина
`/shop potions`. Общий ZIP и остальные JAR не публикуются.

## Доказанная причина и исправление

Skills 2.0.1 помечает зелье ключом `chrdk_skills:skill_xp_v1`, а whitelist
Core 2.0.1 ищет `chrdkskills:skill_xp_v1` — без подчёркивания. Поэтому все 10
штатных PDC-прототипов получали `validGrant=false` и молча исключались из витрины.

DiamondShop RC2 клонирует прототип, строго сверяет исходный токен Skills со SKU и
добавляет второй PDC-ключ для Core. В выданном предмете сохраняются оба:

- исходный ключ нужен Skills для обработки употребления и начисления XP;
- совместимый ключ позволяет Core проверить native frozen grant и recovery.

Это не обход whitelist: отсутствующий, чужой или не соответствующий SKU токен
закрывает товар. Материал, количество, цена, native grant, WAL, финансовые сверки
и recovery не ослаблены. При повторном подтверждении покупки используется тот же
строгий адаптер.

Если витрина всё же пуста, RC2 записывает производителя, `available`, prototype,
`validGrant`, цену и исключение для каждого SKU в `latest.log`.

## Установка и проверка

Остановить сервер, сохранить backup и заменить только DiamondShop на
`chrdk-diamond-shop-2.0.2-rc.2.jar`. Core, Skills и TierForge остаются 2.0.1.
Вайп и удаление JSON не требуются.

После полного запуска:

1. Открыть `/shop potions`: должны быть 10 зелий.
2. Купить одно, выпить и проверить начисление XP соответствующему навыку.
3. Открыть `/shop forge`: должны остаться только 8 расходников Кузни.
4. При любой проблеме прислать строки `[DiamondShop]` из `latest.log`.
