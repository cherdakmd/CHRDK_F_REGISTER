# CHRDK DiamondShop 2.0.2-rc.2

**Пререлиз только `CHRDK_DiamondShop`.** Зелья навыков полностью убраны из магазина.
Общий ZIP и остальные JAR не публикуются.

## Что удалено

- отдельная витрина и GUI десяти зелий;
- команда и автодополнение `/shop potions` и его алиасов;
- кнопки перехода к зельям из рынка и Кузни;
- десять `skill_xp_*` из витрины, цен, названий и описаний магазина;
- возврат в меню зелий после окна количества.

`/shop forge` содержит только восемь расходников Кузни. Дополнительная проверка в
`purchase` отклоняет potion Offer даже при попытке использовать устаревший объект GUI.
Остальной каталог рынка, minor-экономика, native grant, WAL и recovery не меняются.

Сам модуль Skills, уже существующие зелья, их PDC, выпадение и начисление XP не
изменяются. Крафт зелий из кастомных предметов в этот выпуск **не входит** и будет
отдельной задачей позже.

## Установка и проверка

Остановить сервер, сохранить backup и заменить только DiamondShop на
`chrdk-diamond-shop-2.0.2-rc.2.jar`. Core, Skills и TierForge остаются 2.0.1.
Вайп и удаление JSON не требуются.

После полного запуска открыть рынок и `/shop forge`: кнопок и товаров зелий быть не
должно, в Кузне остаются восемь обычных расходников. `/shop potions` больше не
открывает витрину.
