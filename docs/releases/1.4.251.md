# 1.4.251 — встроенный защитный модуль сервера

25 плагинов, Core API 29, банк schema 8, Purpur 26.3 / Java 25.

В CHRDK_Core включён ServerGuard: квоты подключений по IP и общая, ограниченная
таблица адресов, квоты ожидающих авторизации/таймаут, антиспам команд до и после
входа, console-only корни опасных команд без OP-bypass. Namespace, зарегистрированные
aliases и статические commands.yml проверяются. `/guard` — сводка только консоли/RCON.
Настройки `security` работают по умолчанию и в старом config.yml; `/pass reload`
применяет их без пересоздания текущего срока входа.

Пароли, добровольная TOTP, прежняя эскалационная капча, экономика, цены, физика,
ранги и PvP не меняются. Отдельный аддон/прокси не нужен. Управление fill/tp/give/
gamemode/title и другими перечисленными корнями теперь только из консоли/RCON,
даже для OP. Свои обёртки требуется ограничить отдельно. Лимиты нужно проверить
для семьи/NAT и массового легитимного входа.

Защита действует на Bukkit-события, не является сетевым DDoS-фильтром/проверкой
«человек» и не ловит пакеты до pre-login. Ошибка forwarding не повод включать
BungeeCord на прямом сервере. Логи штатных команд не отключаются; модуль пишет
только редкие агрегаты, без паролей, кодов, IP и исходного текста команд.

Подробности и smoke: [SERVER_GUARD.md](../SERVER_GUARD.md).
Перед установкой: остановка, согласованный backup мира/playerdata/JAR/всех данных,
замена 25 JAR одной версии без дубликатов и /reload. Для перехода с 247 и ниже
учесть снятие Queue (248), для банка и магазина — инструкции 250. Нельзя откатывать
старые JAR поверх bank schema 8. Формат: единый chrdk-plugins-1.4.251.zip с 25 JAR
и ОБНОВЛЕНИЕ.txt. Сервер не менялся; живой smoke/нагрузочный тест не выполнялся.
