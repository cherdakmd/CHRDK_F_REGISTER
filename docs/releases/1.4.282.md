# 1.4.282 — номер не использован для стабильного комплекта

**Стабильного выпуска 1.4.282 нет.** Номер остался за серией пререлизов:
`v1.4.282-rc.11` и `v1.4.282-rc.16` собирались из отдельной ветки разработки
(наковальня без команд и TAB, BP ×10, Кузня, восемь PDC-расходников
и `/shop forge`). В стабильную линейку они не вливались: по решению владельца
релиз собирается только из PR #54, без тех 45 коммитов.

Следующий стабильный комплект поэтому получил номер **1.4.283**, а не 1.4.282 —
чтобы один номер не обозначал два разных набора исходников. Этот текст попал
в `ОБНОВЛЕНИЕ.txt` только как пояснение к нумерации: администратору не нужно
искать `chrdk-plugins-1.4.282.zip` или переносить данные пререлиза.

Никаких инструкций по обновлению, новых команд и миграций здесь нет.
Полный порядок для сервера — в [1.4.283.md](1.4.283.md).
