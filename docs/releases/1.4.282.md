# 1.4.282 — отображение оформления клана (кандидат RC.1)

Подготовлено исправление; стабильный релиз, установка на Minecraft-сервер и публикация TradeMC не выполнялись.

- Анимации aurora / shine / pulse передают готовые RGB-цвета символов. Кадр сохраняется после шаблона клана, сериализации, выделения метки в Core и финального рендера чата/TAB; односимвольный тег тоже меняет цвет.
- В TAB один общий таймер обновляет только имена с действующей анимацией. Отключение общего периодического обновления шапки (`tablist.refresh-ticks: 0`) больше не останавливает анимацию. При отключённом TAB или пустом формате имени таймер не запускается.
- В чат попадает кадр на момент отправки; история не переписывается. Красная/зелёная статусная рамка клана сохраняется, цвет эффекта остаётся внутри тега, ник/соседние метки не перекрашиваются.
- Отказ переноса явно говорит «оформление НЕ применено», показывает прежний клан и время разрешённого переноса (часовой пояс сервера). Ограничение 24 часа сохранено: перезапуск, снятие выбора и перевод часов назад его не обходят.
- В GUI и `/clan style status` показано, есть ли активная анимация текущего клана. Личный выбор из другого клана больше не отмечается выбранным в текущем. Предпросмотр не выдаёт лицензию и не применяет эффект.

## Проверка после отдельного разрешения на установку

1. У покупателя с действующим «Клановым комплектом» выбрать `/clan style animation aurora` (либо shine / pulse). Для участника требуется подтверждение главы. Для переноса в другой клан дождаться указанного срока и повторить выбор: автоматического переноса нет.
2. Убедиться, что GUI показывает активную анимацию именно текущего клана. Цвет названия `aurora` из категории «Имя» — статический градиент, это не выбор бонусной анимации.
3. В TAB наблюдать смену RGB на теге и сохранение красной/зелёной рамки. Отправить новые сообщения в разные моменты: меняется кадр новых сообщений, старые остаются прежними.
4. Повторить с `refresh-ticks: 0`, восстановить настройку. Проверить снятие/истечение лицензии, выход владельца из клана и перезапуск: без действующего источника эффект отсутствует.

Добавлены автоматические проверки фактических цветов компонентов в полном пути клан → Core → чат/TAB для всех трёх эффектов, коротких/кириллических/экранированных тегов и четырёх статусных шаблонов, неизменности уже собранного сообщения и строгой границы cooldown с сохранением старой привязки.
