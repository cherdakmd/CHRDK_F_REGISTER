# 1.4.252 — адаптивная защита входа и повторного спама

25 плагинов, Core API 29, банк schema 8, Purpur 26.3 / Java 25.

- Повышенный режим после двух последовательных 10-секундных окон: ≥30 отказов
  с ≥8 разных IP в каждом. Дополнительная квота неизвестных — 12 + 3/сек;
  автоматическое восстановление после 60 секунд без квалифицирующей нагрузки.
  Один IP не включает/не удерживает режим; это индикатор нагрузки, не детектор людей.
- Недавно успешно вошедшая пара UUID+IP получает ограниченный приоритет допуска
  и малую recovery-квоту. Это не пропуск авторизации: пароль/TOTP/баны остаются.
- Допуск PlayerLoginEvent до join учитывает ожидающие соединения, max-players,
  вошедших и резерв. Резервы отдельных соединений истекают через 15 секунд и
  освобождаются при позднем отказе другого плагина; pulse остаётся fallback.
- Три отдельных командных flood-kick за 10 минут: пауза 30 секунд, затем до
  300 секунд. На UUID+IP, не на весь общий адрес. Повтор попытки не продлевает
  паузу, пачка пакетов одного kicked-соединения не размножает strikes.
- guard в консоли/RCON: причины, режим, лимиты, паузы и резервы без IP/UUID/секретов.
  Reload сохраняет историю/давление/дедлайны; после рестарта история оперативная
  обнуляется. Коллекции ограничены, дополнительных HTTP/DNS/файловых записей нет.

Настройки security.defense имеют fallback в старом config.yml. Приоритетным
игрокам не выдаются права и не отменяется лимит ожидающих на IP. Игрокам с новым
IP, 2FA и большим группам за NAT нужно проверить настройки на тестовом сервере.
Обычные авторизовавшиеся боты внутри квот не распознаются автоматически.

TCP/DDoS/пакеты до pre-login не фильтруются. Handshake/forwarding, online-mode,
пароли, опциональная TOTP, экономика, ранги и PvP не меняются. Другие плагины не
изолируются. Подробности, границы и smoke: [SERVER_GUARD.md](../SERVER_GUARD.md).

Установка отдельно: остановить сервер, сохранить согласованный backup миров,
playerdata, JAR и всех данных, заменить все 25 JAR без дубликатов и /reload.
Для старых версий учитывать снятие Queue (248), банк/каталог/откат (250).
Один chrdk-plugins-1.4.252.zip с 25 JAR и ОБНОВЛЕНИЕ.txt. Сервер, TradeMC и
настройки хостинга не менялись; реальный нагрузочный и Minecraft smoke не выполнены.
