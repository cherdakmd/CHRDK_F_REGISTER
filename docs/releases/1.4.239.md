# 1.4.239 — удаление Bosses и «Кладов»

**CHRDK_Bosses и CHRDK_Treasures полностью удалены из проекта и больше не
развиваются.** Нет их исходников, Gradle-модулей, сборочных заданий, JAR в новом
комплекте, записей обновлятора, команд и страниц действующей вики.
Комплект теперь **28 плагинов: CHRDK_Core и 27 аддонов**. Core API **26**.
Purpur 26.3 / Java 25. Выпуск — только общий ZIP с `ОБНОВЛЕНИЕ.txt`.

## Что изменилось

- Удалены пункты двух аддонов в `/menu`, подсказки и автосообщения о них.
  Стоковые настройки обновляются с резервной копией; пользовательские списки
  целиком не перезаписываются. Их старые пункты с именами снятых плагинов или
  командами не показываются, даже если старый JAR ошибочно оставлен установленным.
- Из `/labels`, его подсказок, статуса и палитры источников убрано звание
  кладоискателя. Старое назначение места остаётся пустым, без подмены классом,
  гильдией или другим званием. То же относится к сохранённым пресетам.
- В `/profile` больше нет разделов двух аддонов. Старые провайдеры с этими id
  не регистрируются. Из `/wiki` убраны соответствующие страницы и подсказки.
- `/enchants sources` больше не обращается к удалённому сервису кладов и не
  рекламирует обменник осколков. Остались стол, библиотекари, природные мобы;
  мастерская работает по своим рецептам.
- API `ChrdkTreasureBookInfo` удалён. Метки происхождения `v1:treasure` и
  `v1:shards` оставлены **только для чтения уже выданных книг**; создавать новые
  книги от этих источников API больше не позволяет. Валидность и перенос чар
  не зависят от подписи источника. Корректные старые книги остаются применимыми.
- Исторические release notes, снимки старых конфигов для миграции и банковские
  квитанции сохраняются: они не являются действующими модулями или планом работ.

## Порядок обновления — обязательно для существующего сервера

1. До обновления закрыть доступ игроков и сделать полную согласованную резервную
   копию сервера: миры, playerdata, `plugins/`, банковские данные и журналы выплат.
2. Ещё на старом согласованном комплекте проверить незавершённые денежные выплаты
   Bosses/Treasures. Завершить их штатными механизмами старой версии, включая
   входы владельцев и освобождение места под лимитом банка. Если выплата
   неоднозначна или не может завершиться, **отложить обновление** до ручной
   сверки журналов; не стирать ledger и не повторять выдачу наугад.
3. Штатно остановить сервер. **Убрать оба старых JAR из `plugins/`** по полю
   `name` в `plugin.yml`: `CHRDK_Bosses` и `CHRDK_Treasures` (обычно файлы
   `chrdk-bosses-*.jar`, `chrdk-treasures-*.jar`). Убрать и другие копии этих JAR
   из каталогов автоматической установки/обновления. Папки данных архивировать
   вне активной установки, не уничтожать. Копирование нового ZIP поверх старого
   каталога само по себе два плагина **не удаляет**.
4. Заменить оставшиеся 28 JAR вместе. Убрать дубли старых версий. Проверить
   собственные алиасы, меню, расписания и сторонние интеграции: удалить вызовы
   `/boss`, `/bossadmin`, `/treasures`, `/treasuresadmin` и их алиасов.
5. Запустить сервер и проверить отсутствие двух плагинов, ошибки зависимостей,
   `/menu`, `/labels`, `/profile`, `/wiki`, `/enchants sources` и `/bal`.
   Проверить работу оставшихся аддонов и применение корректной старой книги.

Уже зачисленные деньги в `/bal`, квитанции и данные остальных модулей не
удаляются. Незавершённые обязательства удалённых аддонов автоматически новым
ядром не импортируются: отсутствие двойной выдачи важнее угадывания суммы.
Осколки и прогресс снятых аддонов не конвертируются в алмазы.
Уже выданные вещи не сканируются и не удаляются из инвентарей/миров, но их
особые механики, реализованные только удалёнными аддонами, больше не работают.
Ванильные боссы, bossbar ранга, охота, рыболовные сокровища, навыки и общая
денежная инфраструктура событий сохранены.

Установка на рабочий сервер и live-тесты в рамках этой правки не выполнялись.
