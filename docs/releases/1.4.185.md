# CHRDK 1.4.185 — редкость у мировой добычи

До этой волны тир получала только вещь, вышедшая из крафта, снятая с мёртвого
моба или найденная в кладе. Всё остальное — сундуки в шахтах и крепостях,
затонувшие корабли, рыбалка — приходило обычным предметом без редкости. Теперь
тир разыгрывается в момент появления вещи, поэтому редкость есть не только у
крафта.

## Что изменилось

- **Сундуки и структуры.** Когда лут-таблица наполняет инвентарь
  (`LootGenerateEvent`), подходящая экипировка получает шанс на тир — с теми же
  правилами групп, что и крафт: оружие, броня, инструменты, утилита.
- **Рыбалка.** Пойманная вещь правится ещё на крючке, до подбора
  (`PlayerFishEvent`, состояние `CAUGHT_FISH`).
- **Общий шанс — 25 %**, у каждой группы можно задать свой
  (`world.*-chance-percent`), плюс чёрный список миров. Шанс считается на
  каждую вещь отдельно.
- **Редкость получает только новое.** Инвентари не сканируются: старые вещи
  игроков не переролливаются и не слабеют от случайного «проклятого» тира.
  Это осознанное ограничение — скан выдал бы тир и тому, что лежит в сундуке с
  прошлой волны.
- **Опознание работает как раньше.** При `identify.enabled: true` вещь лежит в
  сундуке (или висит на крючке) «неопознанной», а редкость открывается в
  инвентаре — ровно как у дропа с мобов. При выключенном опознании тир виден
  сразу.
- **Источник виден.** В `item_tier_source` пишется `world`, поэтому
  `/tiers info` показывает, откуда пришла редкость.

## Настройки

```yaml
# tier-forge/config.yml
world:
  enabled: true
  chance-percent: 25          # 0 — не выдаём; 100 — у каждой найденной вещи
  weapons-chance-percent: -1  # -1 = общий, 0 = группе не выдаём
  armor-chance-percent: -1
  tools-chance-percent: -1
  utilities-chance-percent: -1
  loot-enabled: true          # сундуки, бочки и находки структур
  fishing-enabled: true       # пойманная вещь
  world-blacklist: []         # миры без мировой лотереи
```

- Группы и чёрный список материалов общие с крафтом: `craft.armor/weapons/
  tools/utilities` и `craft.material-blacklist`. Выключенная группа не получает
  тир ни из крафта, ни из мира.
- `/tiersadmin reload` перечитывает секцию без перезапуска сервера, а строка
  «мировая добыча» в отчёте `ConfigReport` показывает итоговые шансы и
  выключенные источники.

## Что осталось как было

- **Крафт** — свой шанс в `craft.*`, крафтовая вещь не проходит мировую
  лотерею второй раз.
- **Дроп с мобов** — `mob-drop.*`, включая множитель для боссов и режим
  «только убийство игроком».
- **Клады** — именные находки получают тир через `ChrdkTierApi`, как и раньше.
- **Торговля и награды аддонов** не тронуты: у них нет общего события
  появления, а подделывать выдачу через клик по сундуку — значит задевать уже
  существующие вещи игроков.
