## Пауза между зельями — в конфиге (PR #107)

Выпивание зелий опыта больше не привязано к жёстким 60 секундам. Новый ключ
конфига:

```yaml
xp-potions:
  # Пауза между зельями, секунды (0 и больше). 0 — выпивание без паузы.
  cooldown-seconds: 0
```

- **по умолчанию 0 — зелья выпиваются без паузы** (решение владельца);
- положительное значение — пауза в секундах между зельями (прежнее поведение
  — 60);
- суточного лимита нет (как и в 2.0.6); сообщение о паузе показывается, только
  если значение больше нуля.

При первом запуске нового JAR ключ автоматически дописывается в существующий
`config.yml` (схема `config-version: 4`, backup перед записью, ваши значения и
комментарии сохраняются).

## Исправлен плейсхолдер %left% в сообщении выпивания (PR #107)

Сообщение «Землекопство: +375 XP. Сегодня осталось зелий: %left%» появлялось
на серверах, чей `messages.yml` сохранил текст `xp-potion-used` из сборок
эпохи 2.0.6-разработки (там был суточный остаток зелий). Суточный лимит и
подстановка `%left%` были убраны в итоговой 2.0.6, но старые значения файла
владельца апгрейдер не переписывает. Миграция `messages-version: 4` вычищает
устаревшие `xp-potion-used` и `xp-potion-daily-limit` из файлов владельцев
(backup, повторный старт идемпотентен) и дописывает эталонный текст:
«%skill%: +%xp% XP.» — без плейсхолдеров.

## Установка и первый запуск

1. Полный комплект: 19 JAR одной версии из `chrdk-plugins-2.0.7.zip`;
   `chrdk-vk-2.0.7.jar` и `chrdk-disasters-2.0.7.jar` — отдельно;
   `mine-treasure-1.6.5-ru.zip` **не заменять**.
2. Согласованный backup миров, playerdata, `plugins/CHRDK_*`, финансовых
   JSON/WAL и конфигураций; остановить сервер штатно; заменить комплект без
   `/reload` и без старых дублей JAR.
3. **Не удалять** `shop-data.json`, `bank.json`, `bank-charge.json`,
   `paid-actions.json`, `claims-data.json`, `welcome-gifts.json`,
   `skill-consumables.json` и playerdata.
4. Первый запуск сам выполнит миграции конфига (v4) и текстов (v4) с backup.
   Проверить: `/skills` (выпивание зелья — сразу, без паузы; сообщение
   «+%xp% XP» без `%left%`), `/bal`, `/pass doctor`.
5. Вайп не требуется; неизвестный исход не разрешается автоматически — при
   аномалиях остановиться и сохранить логи.

Область комплекта зафиксирована в [2.0.7.json](2.0.7.json).
