# 1.4.257 — заметные границы всей территории

## Для игроков

- `/claim borders` показывает весь связный участок одного владельца, а не квадрат
  5×5 вокруг игрока. Удалённый конец длинного участка больше не отрезается.
- Между смерженными чанками нет внутренних швов. Отдельные собственные участки,
  диагональные соседи и чужая земля не включаются в этот контур. Границы свободных
  отверстий внутри территории сохраняются.
- Крупные частицы `DUST` в три ряда: свои границы зелёные, чужие золотые,
  свободный чанк голубой. Белые `ELECTRIC_SPARK` отмечают углы сверху.
- Вход в **свою** территорию автоматически запускает показ на 10 секунд.
  Переход между чанками внутри неё не перезапускает таймер. Телепорт на отдельный
  собственный участок запускает новый показ; вход в чужой или арендованный — нет.
- Вход после авторизации и возрождение тоже обрабатываются. Автопоказ не зависит
  от `/claim notices off`, отключения текстовых уведомлений и их кулдауна.
- Повтор `/claim borders` выключает текущий показ. Пока игрок остаётся в той же
  территории, переход в соседний смерженный чанк не включает его заново.

## Нагрузка и настройки

Контур строится по индексу данных без загрузки чанков. Геометрия кэшируется
на время показа и обновляется при изменении данных, переходе в другую
территорию или мир. Один игрок — одна задача, шаг 0,5 секунды, не более 512
частиц за импульс. Курсор проходит все рёбра, а не постоянно первые 512 точек;
сначала распределяются точки по всем рёбрам, затем остальные высоты и искры.
На очень больших административных участках контур рисуется последовательно.
Частицы видит только получатель; дальность видимости и препятствия остаются
ограничениями клиента Minecraft, это не просмотр сквозь блоки.

`general.border-seconds` — длительность ручного и автоматического показа
(10 по умолчанию, 3–60). Новый `general.border-on-own-entry: true` включает
автопоказ. Старый конфиг без этого ключа тоже получает включённое поведение;
удалять конфиги и данные не требуется. Настройки текстовых уведомлений сохранены.
Смерть, выход, отключение плагина и потеря авторизации снимают текущую задачу.

## Обновление

Полный комплект **25 JAR версии 1.4.257**, Core API 30 / schema 8, Classes schema 4.
Экономика, аренда, защита приватов, PvP и развитие классов не меняются.
Форматы сохранений не меняются. Перед отдельной установкой: остановить сервер,
снять согласованный backup миров, playerdata, конфигов и данных всех плагинов,
заменить комплект целиком. Без `/reload`.

После установки проверить длинный/Г-образный участок, двор-отверстие, отсутствие
швов, вход пешком и после `/login`, телепорт на другой собственный участок,
возрождение, `/claim notices off`, повтор команды, потерю авторизации и выход.
Minecraft smoke-test не заменяется unit-тестами и сборкой. Сервер этим выпуском
автоматически не обновляется; материалы TradeMC не изменяются.
