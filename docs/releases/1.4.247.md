# 1.4.247 — актуальные автосообщения

26 плагинов, Core API 27, Purpur 26.3 / Java 25.

Стандартная рассылка переписана: **28 → 44 подсказки**, все 25 аддонов и ядро.
Добавлены недостающие профессии, классы, квесты, заказы, охота и игра вместе.
Есть ссылки-команды `/wiki`, `/menu`, `/profile` и кликабельная `/donate` без дублирования адресов.

Исправлены сообщения об «истёкшем ранге» у не покупавшего его игрока, получении
выручки через `/auction money` и сохранении серии ежедневок после пропуска.
Убраны устаревающие числа достижений/перков, неверная реклама общей косметики и
обещания сохранности при любом перезапуске. Игровой буст не продлевает платный ранг;
2FA остаётся добровольной. Цены и лимиты предлагается проверять в игре.

Точный стоковый набор 1.4.245–1.4.246 обновится при штатном запуске один раз,
с backup. Владелец не теряет интервал, enabled, порядок, префикс и прочие настройки.
Правленый, сокращённый или пустой список не заменяется — его надо сверить вручную.
Миграции с более ранних стоковых версий сохраняются. Обновлён безопасный запасной
набор при отсутствии списка, добавлены регрессии и [инструкция](../AUTO_MESSAGES.md).

Версия вики обновляется из `main` только после успешной полной Java-сборки и
проверок сайта. Это не установка на Minecraft-сервер. Тег/релиз/установка — отдельные
действия. Если выпускается комплект, формат прежний: один `chrdk-plugins-1.4.247.zip`,
26 JAR и `ОБНОВЛЕНИЕ.txt`, без отдельных JAR-assets. При установке сохранить backup,
штатно остановить сервер и соблюдать [инструкции перехода](1.4.245.md); не применять `/reload`.

TradeMC-материалы не готовились и не публиковались. Снятые модули не возвращаются.
Игровые механики не менялись; F03–F12 общего аудита этим шагом не исправлены.
