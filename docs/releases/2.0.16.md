# CHRDK 2.0.16 — Слияние титанов

> **Статус: ВЫПУЩЕНО — уровни ванильных чар выше ванильных максимумов
> переживают совмещение предметов.**
> Правило утверждено владельцем 18.11.2026: «Чары должны поддерживать
> значение ванильных чар больше ванильных значений. Но с пределами».

## Слияние титанов

Раньше совмещение двух предметов на наковальне теряло надванильные уровни:
ванильная механика зажимает результат потолком чары, и «защита 10» при
слиянии превращалась в «защиту IV». Теперь уровни ванильных чар выше
ванильных максимумов переживают любое слияние — «вещь+вещь», «книга+вещь»
и «книга+книга» — и не режутся.

Механика осталась ванильной: уровни одинаковых чар сливаются в +1, разные —
берутся по максимуму. Потолок ванильных чар при слиянии теперь **не ванильный
максимум, а предел 10**: равные уровни дают +1 вплоть до него, а уже более
высокие уровни (например, «защита 10») не режутся — они просто не растут
выше потолка. Слияние без единого усиления не выдаёт результат — как
ванильная наковальня.

Кастомные и ванильные книги по-прежнему совместимы: пара книг даёт одну
книгу с обоими видами чар, конфликтующие группы отклоняют слияние целиком.

## Предел настраивается

Потолок задаёт конфиг «Чар» — `rules.vanilla-level-cap` (по умолчанию 10,
допустимо 1–30). Значение работает только на слияниях: стол зачарований,
книги и лут не выдают надванильных уровней сами.

## Что снять с обновления

Питомцы (`chrdk-pets`) и доска заказов (`chrdk-orders`) сняты ранее и в
комплект не входят: при обновлении с 2.0.15 удалите их JAR-ы из `plugins/`.
`chrdk-disasters` больше не прикрепляется к релизам.

## Обновление

Обычное: комплект **19 JAR одной версии** в общем ZIP (без питомцев и доски
заказов), `chrdk-vk-2.0.16.jar` отдельно, Mine Treasure не трогать.
Положить JAR-ы в `plugins/` и перезапустить сервер: данные игроков не
трогаются, вайп не требуется.
