# CHRDK Generator 2.0.25 — снятие и прокачка ядра

Отдельный JAR генератора для комплекта CHRDK 2.0.23 с Core API 49 или новее, Purpur 26.3 / Java 25. Другие модули в выпуск не входят.

- При снятии производство останавливается, долг безопасно проводится через существующий журнал. Заберите из отдельных окон всю продукцию и топливо, освободите место в инвентаре и уберите предмет с курсора. Сообщения различают содержимое, ожидание выплаты, нехватку места и ошибки сверки. `/gen resume` возобновляет работу. Остановка переживает рестарт.
- Тиры и модули сохраняются за владельцем и конкретным идентификатором ядра, независимо от слота. При передаче ядра другой игрок не получает чужую прокачку. Перерождение сбрасывает улучшения в том числе снятых ядер.
- У генераторов, снятых в старых версиях, ID ядра вместе с прокачкой не хранился. Если старый свободный слот переиспользуется, неподписанная прокачка сохраняется в `legacyUnassigned` в `generator.json`, но не назначается случайному ядру. Для ручной сверки нужны администратор и резервная копия.

Автотесты не заменяют проверку на живом сервере: серверный smoke не проводился. Перед установкой остановите сервер и сохраните согласованную резервную копию миров, playerdata, настроек, генератора, банка и журналов. Замените старый JAR, не оставляйте две версии, не используйте `/reload`. Откат — только с соответствующей согласованной копией данных: старый JAR не поддерживает новую привязку и остановку. Сам релиз ничего не устанавливает.
