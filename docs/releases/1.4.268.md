# 1.4.268 — мосты Core API 33 и отдельный аддон ВКонтакте (`CHRDK_VK`)

## Поставка релиза

В релизе **`v1.4.268`** публикуются два файла:

1. **`chrdk-plugins-1.4.268.zip`** — штатный общий архив сервера (**25 основных JAR одной версии + `ОБНОВЛЕНИЕ.txt`**, совместимый со встроенным обновлятором `/chrdk update`).
2. **`chrdk-vk-1.4.268.jar`** — самостоятельный опциональный аддон **`CHRDK_VK`**, выложенный **отдельным файлом рядом с общим архивом** (не входит внутрь `chrdk-plugins-1.4.268.zip` и не мешает автообновлению основного комплекта).

## Принятые правила `CHRDK_VK` и Core API 33

Аддон **`CHRDK_VK`** (`chrdk-vk-1.4.268.jar`) работает поверх официального VK Bots Long Poll API (`api.vk.com`, v5.199) и мостов **`CHRDK_Core` API 33**:

- привязка игрового аккаунта к профилю ВКонтакте по одноразовому коду `/vk link`
  в личных сообщениях сообщества (`https://vk.ru/chrdk_reborn`), интерактивное
  игровое GUI-меню `/vk` (27 слотов), двухшаговое подтверждение отвязки
  (`/vk unlink confirm` или двойной клик в GUI), лимит по умолчанию — 1 игровой
  аккаунт на 1 `vk_user_id`;
- кнопочная клавиатура бота в личных сообщениях ВКонтакте (`VkKeyboards`, маршрутизация
  `message.payload`) и встроенные (inline) кнопки экстренной реакции **«Сбросить сессии»** /
  **«Заморозить вход»** прямо под оповещениями о входах и о попытках подбора пароля;
- экстренные команды самозащиты из ВК: `/выход` (сброс IP-сессий и завершение
  текущего сеанса онлайн) и `/заморозить` / `/разморозить` (блокировка входа в
  аккаунт в `RegistrationStore` с сохранением после рестарта), а также справочные
  команды `/онлайн`, `/профиль` и `/вики`;
- **пароли и секреты TOTP через ВКонтакте никогда не меняются и не сбрасываются**;
- умный двусторонний мост между глобальным чатом сервера и беседой сообщества ВКонтакте
  (`/chatid` в беседе + `/vkadmin setchat <peer_id>`, `/vkadmin testchat`, обратный поиск
  `/vkadmin lookup <ник|id...>` и модерация моста `/vkadmin chatban <ник|id...> [off]`):
  коалесцирующий анти-флуд буфер `VkChatBatcher`, раскрытие ответов из беседы ВК в
  игровые обращения `↪ @Ник` со звуковым пингом, нативные упоминания `[id...|@Ник]` для
  привязанных игроков, личные переключатели `/vk chat` и `/vk mentions`, проверка `/mute`,
  заморозки входа, `/ignore`, фильтра слов и защита от массовых пингов `@all`/`@online`/`@все`;
- косметическая метка `vk` в `/labels` (`[ВК]` / `[VK Donut]`), однократные
  игровые XP-бусты за первую привязку и подписку на сообщество (с защитой от
  повторного получения при перепривязке), бонус времени покупок каталога для
  активных подписчиков **VK Donut** (через `ShopBonusProvider`, без сложения с
  другими подписками и в рамках потолка бонуса) и автоанонсы новых постов стены.

При пустом токене сообщества `CHRDK_VK` запускается в безопасном автономном
режиме без сетевых запросов. Если `CHRDK_VK` не установлен на сервере, пункты
меню `/menu` и автосообщения с фильтром `plugin: CHRDK_VK` автоматически скрываются.

## Миграция и установка

Основной комплект — **`chrdk-plugins-1.4.268.zip`** (25 JAR + `ОБНОВЛЕНИЕ.txt`,
Core API **33**, bank schema 8, Guilds schema 3, Classes schema 4). Стоковое меню
прежних версий (включая 1.4.267) мигрирует с сохранением резервной копии;
пользовательские меню и тексты не перезаписываются.

Для подключения ВКонтакте положите отдельный файл **`chrdk-vk-1.4.268.jar`** из
ассетов релиза `v1.4.268` в каталог `plugins/` при штатно остановленном сервере
(после обновления основного комплекта до 1.4.268 и полного согласованного backup
миров, `playerdata`, конфигов и данных плагинов). Не использовать `/reload`;
снятый `CHRDK_Queue` не возвращать.
