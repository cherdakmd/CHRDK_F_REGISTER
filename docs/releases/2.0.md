# CHRDK 2.0

Стабильный выпуск для нового сервера после согласованного полного вайпа. Включает
новый Diamond Shop, удаление Auction, minor-экономику и безопасное восстановление
финансовых привязок из 1.5.7 и 1.5.8-rc.1–rc.3.

## Исправления и диагностика

- Diamond Shop не принимает чужой market и не восстанавливает пустой локальный store
  поверх банковской истории. Автоматический adoption разрешён только при local/Core
  sequence `0/0` и отсутствии pending с обеих сторон.
- `/shopadmin recovery` показывает local/Core UUID, sequence, ACK и bankReady.
- При конфликте charge-witness Core пишет в лог и ожидаемые, и фактические метки.
  Это позволяет установить источник операции без удаления NBT или bank.json.
- После авторизации charge-проверка выполняется до общего cash-recovery, поэтому её
  более конкретная причина блокировки не заменяется общим сообщением.
- `/pass doctor` проверяет единую версию всех загруженных CHRDK JAR, доступность
  `bank.json` и отсутствие незавершённых native-обменов. При смешанном комплекте Core
  также выводит SEVERE при запуске. Это диагностика, не автоматический сброс данных.
- Сохранены fail-closed WAL, native witness, receipts, quarantine и запрет повторной
  денежной операции при неизвестном исходе.

## Полный вайп

Версия **не стирает данные сама** и не содержит обхода финансовых блокировок. Для нового
сервера следуйте [чек-листу чистой установки](../operations/clean-wipe-2.0.md).
Нельзя переносить старый `bank.json`, `shop-data.json`, другие финансовые store/WAL или
`playerdata` в новую экономику. Архив старого сервера сохраняется отдельно.

## Проверка перед открытием

1. Полный комплект JAR 2.0, полный restart; старых JAR в `plugins/` и `plugins/update/` нет.
2. `/pass doctor`: единая версия CHRDK, банк доступен, native pending `0`.
3. `/shopadmin recovery`: binding и ACK `true`, local/Core UUID совпадают, sequence `0`.
4. Тестовый игрок: регистрация, вход/2FA, депозит, вывод, покупка и продажа, restart,
   повторный вход без kick и без изменения баланса/инвентаря.
5. Claims, Guilds, Daily, Orders и платные телепорты — smoke только на новых данных.

## Ограничение проверки

Source/CI проверки не заменяют live staging Purpur 26.3. Внешние TradeMC, VK/MAX,
LuckPerms и Plasmo Voice проверяются на сервере отдельно. Не открывайте сервер игрокам,
пока перечисленные выше проверки не пройдены.
