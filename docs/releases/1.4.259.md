# 1.4.259 — точная цена кланового мирного режима

Включает всю реализацию [1.4.258](1.4.258.md): мирные/боевые кланы, алиасы,
10 алмазов с участника в сутки, предоплату состава из казны, дополнительные
сутки до исключения/роспуска лидера и штрафной долг за нападение.

Исправлен редкий случай предпросмотра: военные возвраты сверх потолка казны
восполняют её свободный остаток при расходе. Сравнение только свободных остатков
могло занижать показанную коллективную цену. Теперь учитывается уменьшение
**казны + военных возвратов**. Подтверждённое списание, тарифы, личная доплата,
сроки и форматы данных не меняются. Добавлены четыре теста обычной казны,
полного/частичного восполнения и многодневной оплаты всего состава.

Полный комплект **25 JAR 1.4.259 + ОБНОВЛЕНИЕ.txt**, Core API 31 / bank schema 8,
Guilds schema 2, Classes schema 4. Обновлять весь комплект после остановки
и согласованного backup миров/playerdata, конфигов/данных/WAL; без `/reload`.
Не удалять paid-actions.json/charge WAL и не откатывать отдельным старым Guilds.

Проверки сборки не заменяют Minecraft smoke-test. Сервер не устанавливается
автоматически; TradeMC не изменяется. Правила/команды/ограничения атрибуции PvP
полностью описаны в 1.4.258 и в вики кланов.
