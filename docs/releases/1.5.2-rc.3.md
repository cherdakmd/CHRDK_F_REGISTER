# 1.5.2-rc.3 — пререлиз (не стабильный выпуск)

**Версия:** `1.5.2-rc.3` · **Платформа:** Purpur 26.3 / Java 25 · Core `API42`
**Дата:** 7 ноября 2026 года · **Ветка:** `arena/35241455-chrdk-f-register`
**Latest остаётся `v1.5.1`.** Стабильный `v1.5.2` зарезервирован; `v1.5.2-rc.1`,
`v1.5.2-rc.2` и все прежние теги, заметки и ассеты не переписываются.

Это **полноценная по составу версия**, которой ещё предстоит развиваться в
следующих release candidate: она объединяет восемь коммитов ветки поверх
`v1.5.2-rc.2` плюс коммит версии. Пререлиз, а не стабильный выпуск.

1. **`483ecee`** — бумажные документы: чек-лист живого smoke для rc.2 и аудит
   автообновления конфигов. Живой smoke не проводился.
2. **`adc9e4d`** — схема версий конфигов: `ConfigSchemaEngine`, `ConfigUpgrader`,
   23 точки вызова в ядре и 22 аддонах. Новые ключи `messages.yml` дописываются
   в файл владельца физически, значения и комментарии не перезаписываются;
   `config-schema.yml` нет, действует base v1, 8 JUnit-тестов.
3. **`0cfd0b4`** — CHRDK_VK: все повторяющиеся напоминания о привязке (чат,
   пинги при действиях, строка над хотбаром, звук) делят один общий кулдаун
   60 минут на игрока. Первый join-блок сохранён, relog в течение часа его не
   повторяет. `social.reminder-seconds: 3600`, предел 10..86 400.
4. **`a6c0180` / `19dd735` / `470d614`** — `CHRDK_Disasters`: собственный
   MIT-модуль катастроф (пыльная буря, метеоритный дождь, землетрясение),
   таймеры на игрока, уровни, команды, защита приватов `CHRDK_Claims` до

   `ConfigUpgrader`/`Messages`, JUnit, вики. Всё выключено по умолчанию.
   Зарегистрирован в меню, авторассылке и `settings.gradle` (23-й модуль).
5. **`d0ea8c1` / `3454b6c`** — разовый случайный стартовый комплект новичка:
   броня, инструменты, смешанные артефакты, `1000` алмазов на `/bal` и `32`
   физических в инвентарь. Выдаётся один раз после авторизации, флаг по UUID в
   `starter-kits.json`. Стартовый подарок не расходует `dailyCap` Skills.
6. **Коммит версии** — `plugin_version=1.5.2-rc.3`, памятка, заметка, README,
   вики, реестры standalone-ассетов и workflow релиза.

`API_VERSION` ядра **не повышался** (остался 42): новый модуль и стартовый
комплект не меняют публичный контракт.

## Конфиги и данные

Новые/правленые файлы: `disasters/config.yml`, `disasters/messages.yml`,
`disasters/plugin.yml`, `src/main/resources/config.yml` (секция `starter-kit`),
`src/main/resources/messages.yml` (`starter-kit.granted`), `vk/config.yml`,
меню и авторассылка ядра, `wiki/` (39 страниц), `update-memo.txt`.

- Сравните авторские значения с эталоном; чужие конфиги не перезаписываются.
- Секция `starter-kit` при отсутствии работает на значениях по умолчанию —
  правка существующего `config.yml` не требуется.
- `CHRDK_Disasters` по умолчанию выключен: включайте `disasters.enabled`,
  `worlds` и нужные `kinds.*` явно. Землетрясение выключено отдельно.
- `starter-kits.json` создаётся ядром автоматически; не удаляйте его, иначе
  новички (уже получившие комплект) получат его повторно.
- 26 карточек TradeMC и цены рангов — снимок стабильного `1.5.1`, 27-го SKU
  нет. Social-посты и стабильная новость ВК для пререлиза не выпускаются.
