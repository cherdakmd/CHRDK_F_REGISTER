# RC11: границы проверки обычной наковальни

Кандидат `1.4.282-rc.11`, Core API41. Документ не является разрешением на релиз,
установку, изменение production-сервера или внешнюю публикацию.

## Что проверяется автоматически

| Путь | Проверка | Где |
|---|---|---|
| Core actual/display | Полные 40/80+, визуальные ≤39, override=39, stale result, полная скидка и отсутствие повторной скидки/overflow | `AnvilCostsTest`, `AnvilTakeTest` |
| Ручная выдача | Исполняется настоящий `AnvilCostListener.take`, а не копия алгоритма: один расход XP, точный остаток второго слота, повторный клик | `AnvilTakeTest` |
| Отказы | Auth, online/dead, Survival/Adventure/Creative/Spectator, доступ к наковальне, курсор, Shift/цифры/ПКМ/drop/offhand/double-click | `AnvilTakeTest` |
| Source binding | Входы/количество/результат/rename/material count/maximum/mode/price; закрытие окна; невозможный расход | `AnvilTakeTest`, `ForgeMaterialTest` |
| Откат | Однократное исключение после изменения result/left/right/XP/cursor: входы, курсор, level/total/progress восстановлены; событие успеха не отправлено | `AnvilTakeTest` |
| Rename-only | Исключение 39 не переносится на изменение чужого payload; скидка кузнеца после cap | `AnvilTakeTest`, `AnvilCostsTest` |
| Уведомление | Core post-paid event синхронный, неотменяемый, defensive copies; новый/усиленный известный curse, не light/старый/удалённый/foreign | `AnvilTakeTest`, `AnvilPaidCurseTest` |
| Forge | Фиксированные цены, eligible target/pool, UID+sequence determinism, snapshots/выбор, переполнение, stock/custom/empty | `ForgeMaterialTest` и прежние тесты TierForge |
| Чары | Pure/mixed, native conflicts, повторный prepare, generation, накопительная работа, максимумы | `AnvilQuotesTest`, `AnvilPriceTest` и прежние тесты Enchants |
| CI transport | Только распознанный transient dependency download, все секции --continue, максимум 3 попытки; compiler/test/unknown/401/403/404/PKIX/OOM не повторяются; настоящий subprocess/exit/log | `test_gradle_build.py` |
| PAPI build input | Официальный GitHub release 2.12.3, pinned SHA-256/размер/классы, атомарный cache, отказ при подмене/ошибке; все 8 потребителей используют compileOnly | `test_prepare_papi.py` |
| Комплект | Gradle build всех модулей, сообщения, retired/release regressions, wiki/freshness/data/links/browser и offline social | `.github/workflows/build.yml` |

В `AnvilTakeTest` адаптеры auth/доступа/звука/логгирования подменены. Предметы —
модель `ItemStack` с копируемым payload, а не настоящие `CraftItemStack` и NBT.
Модель НЕ проверяет сетевой протокол клиента, физику блока, CraftItemMeta/NMS,
другие установленные плагины или запись playerdata на диск. Ошибки инъецируются
однократно; тест не обещает восстановление при постоянной поломке самой платформы.

## Незакрытый live smoke — блокер выпуска/установки

Нужен отдельный изолированный staging после разрешения и с резервной копией, не
production. Для каждого пункта записать версию клиента/сервера, входы/XP до и после,
фактический результат и PASS/FAIL. Пока эти пункты **НЕ ВЫПОЛНЕНЫ**.

1. **Ванильные 39/40/80+.** Обычные починка, соединение и книги. Нет «Слишком дорого»;
   настоящая цена в чате; недостаток полного XP не выдаёт вещь. При достатке списывается
   ровно полная сумма и нужное количество материала. Проверить XP progress и остаток.
2. **Переименование и профессия.** Только имя, удаление имени, дорогая prior-work вещь,
   кузнец со скидкой/без. Cap до скидки (например, 39 → 35 при 10%). Новые чары/чужие
   данные не маскируются под rename-only; обычные недорогие операции не ломаются.
3. **Каждый расходник.** Кристалл — все ступени/максимум; ядро — все eligible варианты
   и max/отсутствующее улучшение; печать — все активные ✧, другой совместимый same-tier
   результат без дубля. ПКМ выбирает, ЛКМ пустым курсором платит. Интерфейсный лор не выдан.
4. **Без бесплатного переролла.** Preview/закрытие/перестановка/relog не меняют результат;
   оплаченный шаг меняет последовательность. Проверить чары/имя/прочность/чужие PDC/UID,
   netherite-перенос; поддельный обычный материал не заменяет настоящий расходник.
5. **Отложенный Forge take.** Между кликом и тиком закрыть окно/сменить входы/мир/config/
   право/auth, занять курсор. Нет выдачи и платы. Спам/два пакета, Shift/цифры/offhand/drop,
   drag в result и полный инвентарь. Входы не дублируются и возвращаются при закрытии.
6. **Кастомная книга.** Pure и mixed при цене 40+, обычные конфликты/максимумы, смена
   имени, повтор Prepare, reload. Доплата не удваивается; stale quote не забирается.
   Новое/усиленное проклятие сообщает один раз после реального успеха; preview/отказ — нет.
7. **Lifecycle/блок.** Реальная наковальня, расстояние/другой мир; 12% wear, сохранение
   facing, chipped/damaged/break и отмена AnvilDamagedEvent. Disable Core/TierForge закрывает
   окно и возвращает источники без preview-выдачи. Проверить фактическую защиту территории.
8. **Сохранение.** Чистый stop/start: предметы/XP/последовательность/коллекция не теряются.
   Аварийное завершение JVM проверять отдельно на копии; playerdata не crash-atomic ledger.
9. **Остальное.** Слияние/старая ковка/настройка аметиста, stock/custom/empty messages и
   старый лор, штатные notify/collection. Снять MSPT/пакеты на реальной ожидаемой нагрузке.

Отчёт CI и зелёная сборка не заменяют этот список и не дают разрешения на выпуск.


## Устранение устойчивого отказа Maven PlaceholderAPI

Ограниченные повторы сами по себе не починили длительный таймаут extendedclip.
CI готовит официальный plugin release **той же версии 2.12.3** с GitHub:
`https://github.com/PlaceholderAPI/PlaceholderAPI/releases/download/2.12.3/PlaceholderAPI-2.12.3.jar`.
Зафиксирован SHA-256 `fde03259f5af6938f3c33eeb4d814000a1adabf1d2304ce14970be81f609a437`
(официальный release asset `465403523`, digest из GitHub API). Это официальный
полный plugin JAR, а не побайтовая копия тонкого Maven API JAR.

Он применяется только как compileOnly вход через `-Pchrdk.papiJar=build/dependencies/...`.
Не распаковывается в наши JAR, не лежит в `build/libs`, не входит в комплект и не
устанавливается. Без свойства локальная Gradle-сборка сохраняет прежнюю Maven-зависимость.
Нет случайного mirror, mutable latest, отключения TLS или принятия неподписанного hash.
Несовпадение SHA/размера/ожидаемых классов и невалидный cache останавливают сборку;
при сетевом отказе подготовки нет обхода на непроверенный артефакт. 7 отдельных тестов.
