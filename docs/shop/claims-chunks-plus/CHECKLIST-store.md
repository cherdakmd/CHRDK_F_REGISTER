# Чек-лист карточки в панели магазина

Используйте при заполнении формы (TradeMC / аналогичная панель RCON-доставки).

| Поле | Значение | Статус |
| --- | --- | --- |
| Название товара | `+8 чанков привата навсегда` | ✅ |
| Стоимость, ₽ | `159` | ✅ |
| Изображение | `claims-chunks-plus.png`, оригинал 1200×1200 PNG, без текста | ✅ загрузить оригинал, не скриншот |
| Категория | `Приваты` (или своя существующая категория приватов) | ✅ |
| Команды выдачи | `pass shopbuy %username% claims-chunks-plus` — одна строка, без `/` | ✅ |
| Команды снятия привилегии | **ПУСТО** | ✅ критично: бонус вечный, снимать нечего |
| Описание | `description-store-plain.txt` или `description-store-bbcode.txt` | ⚠️ заменить текущий текст |
| Срок / Дни / Время выдачи | **пусто, «без срока» или «навсегда»; НЕ 30** | ⚠️ проверить поля ниже на форме |
| Автоповторы доставки / ретраи | **выключены** | ⚠️ повтор RCON = ещё +8 за тот же платёж |
| Подстановка `%username%` | панель обязана подставлять реальный ник | ⚠️ проверить в настройках команды |

## Что исправить в уже заполненной форме

1. **Смешанная разметка.** В описании одновременно `[b]...[/b]` и `**...**`:
   первое работает только в BBCode-редакторе, второе — только в Markdown.
   На форме обе строки видны буквально. Возьмите один готовый файл целиком:
   `description-store-bbcode.txt` (если панель понимает BBCode) или
   `description-store-plain.txt` (универсально, без разметки). Не смешивайте.
2. **Символ `⛁`.** Замените на слово «алмазов»: в кодировке панели и у части
   клиентов значок может отобразиться квадратом. В готовых файлах уже заменён.
3. **Обрезанный текст.** В форму попали только первые три абзаца. В готовых
   файлах добавлены расчёт лимита, повторная покупка, перенос ника, что товар
   не даёт, и явное пояснение про «30 дней».
4. **Срок ниже на форме.** Если есть поле «Срок», «Дни», «Период» или «Время
   выдачи» — не ставьте 30. `days: 30` в `config.yml` — служебное поле
   `ShopCatalog`, а не срок действия бонуса. Иначе покупатель увидит «30 дней»
   при названии «навсегда», а панель попытается снять привилегию.
5. **Ретраи.** Генератор кита прямо предупреждает: плагин не отличает повтор
   RCON-команды от новой покупки. Один платёж = одна команда, без
   автоматических повторных отправок. Иначе +8 начислится дважды.
6. **Проверьте второй платёж на тесте.** Убедитесь, что команда выдачи
   выполняется при КАЖДОЙ покупке, а не только при первой: на этом держится
   «повторная покупка добавляет ещё +8».

## Согласование с репозиторием

У SKU стоит `trademc-export: false`: официальный комплект TradeMC по-прежнему
содержит 26 карточек и цены рангов снимка 1.5.1, а `tools/trademc/audit.py`
это проверяет. Ручная карточка — владельческое действие вне генерируемого
комплекта; флаг в репозитории не меняем, иначе аудит 26 карточек сломается.
Команда выдачи при этом должна остаться ровно такой же, как в
`tools/trademc/build.py` (`pass shopbuy %username% <id>`). Если карточка
должна стать частью официального кита — это отдельное решение: ранее вариант
создания новой карточки TradeMC был отклонён.
