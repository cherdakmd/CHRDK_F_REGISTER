# Набор «+8 чанков привата навсегда»

Готовый комплект материалов для товара `claims-chunks-plus` (159 ₽, разово,
бонус вечный). Архив `claims-chunks-plus-kit.zip` лежит рядом, в
`docs/shop/`, и скачивается прямо из репозитория.

## Что внутри

| Файл | Содержание |
| --- | --- |
| `claims-chunks-plus.png` | Картинка товара, 1200×1200 PNG, без текста и водяных знаков |
| `name.txt` | Название товара: точная строка для `config.yml` (MiniMessage), вариант без разметки, короткие варианты, ID |
| `command.txt` | Команда выдачи через RCON, внутренняя команда, админская сверка, команды игрока |
| `description.md` | Подробное описание для карточки товара: краткий текст витрины, полный текст, что товар НЕ даёт, FAQ |
| `description-store-plain.txt` | **Готовое описание для вставки в панель магазина** — чистый текст, без Markdown/BBCode и без спецсимволов |
| `description-store-bbcode.txt` | То же описание с `[b]...[/b]`, если панель понимает BBCode |
| `CHECKLIST-store.md` | Чек-лист полей формы: что верно, что исправить, почему поле снятия привилегии пустое |
| `product.yml` | Готовый фрагмент `shop.products` для ручной вставки в `config.yml` |
| `manifest.json` | Машиночитаемые метаданные: id, цена, вечный бонус, команды, картинка, версия |
| `SHA256SUMS.txt` | Контрольные суммы всех файлов набора (кроме самого этого файла) |
| `README.md` | Этот файл |

## Как использовать

1. **Витрина `/pass`.** Ничего добавлять не нужно: SKU уже есть в эталонном
   `src/main/resources/config.yml`, а `ClaimsChunksProductMigration` аддитивно
   допишет его в `config.yml` работающего сервера при старте или `/pass reload`,
   не перезаписывая цены и сроки владельца. Для ручной вставки — `product.yml`.
2. **Картинка.** Используйте PNG как есть: для GUI-иконки уменьшите до 64×64
   или 128×128, для сайта/соцсетей — оригинал 1200×1200. Текст в изображение
   не вшит, поэтому название и цену можно верстать отдельно.
3. **Тексты.** `name.txt` → поле `name`, краткое описание из начала
   `description.md` → поле `description` (копия уже стоит в `product.yml`).
   Полный текст из `description.md` — для лендинга или поста. **Для поля
   «Описание товара» в панели магазина берите `description-store-plain.txt`
   (или `description-store-bbcode.txt`) целиком**: там нет Markdown, `⛁` и
   смешанной разметки, которые в WYSIWYG/BBCode-редакторе отображаются
   буквально. Перед публикацией пройдите `CHECKLIST-store.md`.
4. **Выдача.** `pass shopbuy %username% claims-chunks-plus` от консоли/RCON.
   Отдельной карточки TradeMC не создавайте: у товара `trademc-export: false`,
   26 действующих карточек и цены рангов остаются снимком 1.5.1.

## Честные формулировки

Пишите **«навсегда, без продления»** и **«+8 к лимиту чанков»**. Не пишите
«30 дней», «подписка», «продлить», «чанк в подарок», «без ренты»: `days: 30` —
техническое поле каталога, земля не выдаётся, а рента 10 ⛁/сут за чанк
сохраняется. Покупка продаёт удобство/статус, а не игровое преимущество.
