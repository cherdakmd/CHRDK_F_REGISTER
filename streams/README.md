# CHRDK_Streams — стримерская программа сервера

Аддон ядра **CHRDK_Core** (версия `1.4.116-SNAPSHOT`): подтверждает канал стримера
на Twitch или VK Play Live, платит **днями проходки** за эфир и даёт зрителям
небольшую награду за просмотр. Только проходка: никаких ресурсов, снаряжения,
кейсов и преимуществ в бою — ни стримеру, ни зрителю.

```
plugins/
  CHRDK_Core.jar       — обязателен (API v6, Messages, выдача проходки)
  CHRDK_Streams.jar    — этот модуль
  PlaceholderAPI.jar   — необязателен (плейсхолдеры в TAB/скорбордах)
```

`plugin.yml`: `depend: [CHRDK_Core]`, `softdepend: [PlaceholderAPI]`.
Без ядра аддон не запускается — это лучше, чем молча не выдавать награды.

---

## 1. Что получает каждая сторона

| Кто | Что | Сколько |
| --- | --- | --- |
| Стример | дни проходки за подтверждённый эфир | 60 минут эфира = 1 сутки |
| Стример | пометка в чате и TAB | жирный ник + `[СТРИМ]`, в TAB мигает |
| Зритель | дни проходки за просмотр | 120 минут = 1 сутки, но не больше **1 в день** и **30 всего** |
| Сервер | контент и предсказуемая экономика | потолки ниже, чем у стримера; награда soft |

Потолки стримера: `6` суток в календарные сутки (UTC) и `365` всего.
Потолки зрителя жёстче намеренно: смотреть должно быть приятно, но не выгоднее,
чем стримить самому, и точно не выгоднее, чем просто играть.

---

## 2. Как стример подтверждает канал

1. `/stream link twitch <канал>` или `/stream link vkplay <канал>` — плагин
   выдаёт код `CHRDK-XXXX` и ссылку на канал.
2. Стример выходит в эфир и **вставляет код в название стрима**.
3. `/stream check` — плагин спрашивает площадку, идёт ли эфир, и ищет код в
   названии. Код сверяется терпимо: регистр, дефисы и эмодзи не важны.
4. После подтверждения каждый опрос площадки (по умолчанию раз в 120 секунд)
   засчитывает время эфира, пока игрок на сервере.

Проверка кодом в названии — единственный способ доказать владение каналом
без OAuth. `streams.require-verified: false` отключает её (только для тестов).

---

## 3. Как зритель получает дни

1. **Стример включает просмотр:** `/stream viewers on`. Плагин выдаёт код
   `WATCH-XXXX`; стример показывает его на экране эфира (оверлей/название).
   Код меняется каждые `code-window-minutes` (10 по умолчанию).
2. **Зритель подаёт заявку:** `/stream watch <стример>` — он становится
   участником программы у этого стримера.
3. **Стример подтверждает фолловера:** `/stream viewer accept <ник>`.
   Автоматической проверки подписки нет: Twitch не отдаёт список фолловеров без
   OAuth каждого зрителя, у VK Play Live официального API подписчиков нет.
   Подтверждение стримером и есть проверка «ты правда подписан».
4. **Зритель вводит код из эфира:** `/stream code WATCH-XXXX`. Плагин в этот
   момент проверяет на площадке, что эфир идёт, и только тогда начисляет минуты.

Первое введение кода после подтверждения даёт **0 минут** — оно только
запускает счёт. Время до заявки, до подтверждения и до первого кода не
засчитывается.

```
просмотрено 120 мин → +1 сутки проходки
не больше 1 награды в календарные сутки (UTC)
не больше 30 суток за всё время с просмотра
```

Прогресс принадлежит зрителю (`streams-viewers.json`), поэтому смена канала
или `/stream watch stop` не сбрасывает дневной и общий потолок.

## 4. Команды и права

| Команда | Кто | Что делает |
| --- | --- | --- |
| `/stream link <twitch\|vkplay> <канал>` | стример | привязать канал, получить код проверки |
| `/stream check` | стример | проверить код в названии эфира |
| `/stream status` | стример | канал, эфир, накопленные минуты, награды |
| `/stream unlink` | стример | отвязать канал |
| `/stream viewers [on\|off]` | стример | включить/выключить просмотр, показать код и заявки |
| `/stream viewer <accept\|deny> <ник>` | стример | подтвердить или отклонить зрителя |
| `/stream watch <стример>` | зритель | подать заявку на просмотр |
| `/stream watch stop` | зритель | перестать смотреть (прогресс сохраняется) |
| `/stream watching` | зритель | канал, статус заявки, минуты, сегодня/всего |
| `/stream code <код>` | зритель | ввести код из эфира и получить минуты |
| `/stream stats` | админ | сводка по программе |
| `/stream reload` | админ | перечитать `config.yml` и `messages.yml` |

Права:

- `chrdkstreams.use` — всё вышеперечисленное, кроме админского; по умолчанию у всех;
- `chrdkstreams.admin` — `/stream stats` и `/stream reload`; по умолчанию у операторов.

Псевдонимы команды: `/streams`, `/strimer`. `/stream` без аргументов показывает
обе роли (стример и зритель), а если канал уже привязан — ещё и статус стримера.

## 5. Метка стримера

Подтверждённый канал получает:

- **чат и личные сообщения** — `<bold>Ник</bold> <red>[СТРИМ]</red>`;
- **список игроков (TAB)** — та же метка, но цвет меняется каждые
  `blink-ticks` (15 тиков ≈ 0,75 с): это и есть мигание;
- **имя над головой не трогается**: оно строится из команд scoreboard, а ядро
  использует их для сортировки TAB — перекраска из аддона сломала бы порядок.

Если в ядре задан `tablist.player-name-format`, аддон не управляет именами в
TAB (ядро всё равно перезапишет). Добавьте `%player_tagged%` в формат ядра —
это ник с метками аддонов, разметка доверенная; `%player%` по-прежнему
экранируется.

В чате метка статичная: сообщение нельзя «мигать» задним числом. Метку можно
выключить (`streams.tags.enabled: false`) или переименовать
(`streams.tags.text`, до 16 символов), не выключая программу.

## 6. Антифрод

| Правило | Зачем |
| --- | --- |
| Код `CHRDK-XXXX` в названии эфира | доказать владение каналом без OAuth |
| Код `WATCH-XXXX` меняется каждые 10 мин | «зашёл один раз и ушёл» не работает: нужен свежий код |
| Эфир проверяется в момент чек-ина | офлайн-канал не засчитывается |
| Чек-ин не чаще раза в 5 минут | один код нельзя вбить десять раз подряд |
| Кредит не больше окна кода | вернулся через час — получил максимум 10 минут |
| Первый код = 0 минут | время до заявки и подтверждения не засчитывается |
| Потолки 1/день и 30 всего | просмотр не превращается в бесплатную игру |
| Прогресс хранится на зрителе | смена канала не сбрасывает потолки |
| `require-online: true` у стримера | нельзя включить эфир и уйти |

Фолловер-проверка автоматизируется только там, где площадка это позволяет;
сейчас — подтверждение стримером. Это осознанное ограничение, а не недоделка.

## 7. Конфигурация

`plugins/CHRDK_Streams/config.yml` (все ключи с русскими комментариями):

```yaml
general:
  locale: ru                    # messages.yml или messages_<locale>.yml

streams:
  enabled: true                 # выключатель программы целиком
  minutes-per-day: 60           # минут эфира = 1 сутки
  max-days-per-day: 6           # потолок наград в календарные сутки (UTC)
  max-total-days: 365           # потолок всего; 0 — без потолка
  poll-seconds: 120             # период опроса площадок, минимум 60
  max-credit-minutes: 10        # максимум за один опрос (защита от простоя)
  require-online: true          # считать эфир только пока игрок на сервере
  require-verified: true        # требовать код в названии эфира
  min-viewers: 0                # минимум зрителей, чтобы эфир считался
  announce: true                # писать игроку о награде

  tags:                         # метка стримера (волна 7)
    enabled: true
    text: "СТРИМ"               # без разметки, до 16 символов
    chat-color: "red"           # цвет метки в чате
    blink-ticks: 15             # период смены цвета в TAB
    color-a: "red"
    color-b: "dark_gray"
    tab: true                   # управлять именем в списке игроков

  viewers:                      # награды зрителям (волна 7)
    enabled: true
    minutes-per-day: 120        # 2 часа просмотра = 1 сутки
    max-days-per-day: 1
    max-total-days: 30
    code-window-minutes: 10     # как часто меняется WATCH-код
    checkin-min-minutes: 5      # не чаще одного чек-ина
    require-approval: true      # заявку подтверждает стример (фолловеры)

  twitch:
    enabled: true
    client-id: ""               # https://dev.twitch.tv/console/apps
    client-secret: ""
    token: ""                   # готовый app-токен вместо секрета

  vkplay:
    enabled: true
    api-url: "https://api.vkplay.live/v1/blog/%channel%/public_video_stream"
```

Значения зажимаются в разумные границы: опечатка в конфиге не роняет плагин и
не ломает арифметику наград. Цвет метки проверяется по палитре MiniMessage
(или `#rrggbb`); неизвестный цвет заменяется запасным, а не ломает сообщение.

VK Play Live работает без ключей (публичный эндпоинт канала). Twitch без
`client-id`/`client-secret` (или готового токена) сам выключается — остальные
площадки продолжают работать.

## 8. Сообщения

Все тексты — `plugins/CHRDK_Streams/messages.yml` (100 ключей, MiniMessage).
Загрузка: `Messages.load(plugin, locale, logger)`; `/stream reload` перечитывает
файл без рестарта. Плейсхолдеры — `%ключ%`, экранирование делает ядро.
Никаких хардкод-строк в коде: тексты правятся без пересборки.

---

## 9. Данные на диске

| Файл | Что внутри |
| --- | --- |
| `streams-data.json` | привязки каналов: платформа, канал, код подтверждения, прогресс стримера |
| `streams-viewers.json` | настройки просмотра у стримеров, заявки/подтверждения зрителей, прогресс зрителей |

Запись атомарная (temp + move), чтение терпимое: битая строка пропускается и
логируется, остальные данные сохраняются. Прогресс зрителя — отдельная секция,
поэтому отписка и смена канала не обнуляют потолки.

Перед обновлением/переносом сервера достаточно скопировать папку
`plugins/CHRDK_Streams` целиком.

## 10. PlaceholderAPI (мягко)

Только сохранённые данные, никаких сетевых запросов в плейсхолдере.

| Плейсхолдер | Значение |
| --- | --- |
| `%chrdkstreams_channel%` | канал стримера или `—` |
| `%chrdkstreams_platform%` | Twitch / VK Play Live |
| `%chrdkstreams_verified%` | «да» / «нет» |
| `%chrdkstreams_pending%` | минут эфира до следующих суток |
| `%chrdkstreams_today%` | суток получено сегодня |
| `%chrdkstreams_days%` | суток получено всего |
| `%chrdkstreams_rule%` | минут эфира за сутки (из конфига) |
| `%chrdkstreams_max_today%` | дневной потолок |
| `%chrdkstreams_watching%` | чей эфир смотрит игрок |
| `%chrdkstreams_watch_pending%` | минут просмотра до следующих суток |
| `%chrdkstreams_watch_today%` | суток за просмотр сегодня |
| `%chrdkstreams_watch_days%` | суток за просмотр всего |
| `%chrdkstreams_watchers%` | подтверждённых зрителей у стримера |

## 11. Интеграция с ядром

- **Проходка** — `ChrdkRegisterApi.grantPass(ник, дни, "streams:watch")`
  (стример — `streams:<платформа>`). Ядро само пишет аудит
  `PASS_GRANT_MANUAL`, шлёт уведомление в Discord, синхронизирует LuckPerms и
  вызывает `PassGrantedEvent`. В поздравлении игрок видит «наградой стримерской
  программы», а не «выдано администратором».
- **Оформление ника** — API v6: `registerNameTag("streams", provider)` /
  `unregisterNameTag("streams")`. Провайдер получает ник и уже оформленное имя
  (`NameTagProvider.decorate`), возвращает новое; сбой провайдера не ломает чат.
  На ядре старше v6 вызов защищён от `LinkageError`: метка просто не появится.
- **Тексты** — только через `Messages` ядра.
- **Нет ядра — нет наград**: аддон пишет предупреждение в лог и продолжает
  работать без выдачи (проверка `coreApi() == null` в каждом месте выдачи).

## 12. Ограничения

- Список фолловеров не проверяется автоматически — подтверждает стример.
- У VK Play Live нет публичного API подписчиков; у Twitch он требует OAuth
  каждого зрителя.
- Имя над головой не оформляется: команды scoreboard заняты сортировкой TAB.
- Награда — только проходка. Ни ресурсов, ни снаряжения, ни кейсов, ни
  преимуществ в бою: политика сервера запрещает продавать и дарить игровую силу.

## 13. Структура кода

| Класс | Роль |
| --- | --- |
| `StreamPlugin` | запуск, конфиг, регистрация команды/метки/плейсхолдеров |
| `StreamConfig` | разбор и зажим `streams.*`, включая `tags` и `viewers` |
| `StreamPlatform` | Twitch / VK Play Live, ссылки на каналы |
| `StreamClient`, `TwitchClient`, `VkPlayClient` | HTTP и разбор ответов площадок |
| `LiveStream` | снимок эфира: идёт ли, название, зрители |
| `StreamBinding`, `StreamStore` | привязка канала и прогресс стримера |
| `StreamService` | опрос площадок, начисление эфира, выдача проходки |
| `StreamRewards` | чистая арифметика наград: пороги, потолки, полночь UTC |
| `StreamVerification` | коды `CHRDK-XXXX` и терпимая сверка |
| `StreamerTags`, `StreamerTagService` | жирный ник, `[СТРИМ]`, мигание в TAB |
| `ViewerSettings`, `ViewerStore` | настройки просмотра, заявки, прогресс зрителей |
| `ViewerBinding` | жизненный цикл заявки зрителя |
| `ViewerCodes`, `ViewerService` | коды `WATCH-XXXX`, чек-ины и награды за просмотр |
| `StreamCommandHandler` | `/stream`: команды, права, автодополнение |
| `StreamPlaceholders` | плейсхолдеры PlaceholderAPI |

Чистые классы (`StreamRewards`, `StreamerTags`, `ViewerCodes`, `ViewerBinding`,
`ViewerSettings`) не зависят от Bukkit — их поведение закреплено юнит-тестами.

Сборка и тесты — `./gradlew build` из корня монорепозитория (ядро и все
аддоны, 17 JAR).

## 15. Обновление и откат

1. Остановить сервер (или выгрузить аддон штатным менеджером).
2. Заменить `CHRDK_Streams.jar`; `config.yml` и `messages.yml` не перезаписываются
   автоматически — новые ключи появляются в логе/документации.
3. Запустить сервер, проверить `/stream status` и `/stream viewers`.
4. Откат: вернуть прежний JAR; `streams-*.json` совместимы по ключам, битые
   записи пропускаются.

Версия `1.4.116-SNAPSHOT` не тегируется: тег и GitHub-релиз создаются отдельной
командой. История волн — в корневом `README.md`.
