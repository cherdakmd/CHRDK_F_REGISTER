# Текстуры нового лута мобов

В общий ресурс-пак добавлены семь отдельных моделей: три группы эссенций и
четыре сущности вариантов мобов. Новые предметы получают их при включении
`textures.loot-items: true` в `plugins/CHRDK_Mobs/config.yml`. По умолчанию
опция выключена; установите и проверьте актуальный объединённый пак до её
включения: старые архивы этих моделей не содержат. Без пака при включённой
опции клиент может показать отсутствующую текстуру.

Модель назначается только в момент создания лута, а не при подборе или чтении
инвентаря. Ранее выданные предметы сохраняют вид и распознаются по прежнему PDC;
их тип, опыт, количество и эффекты не меняются. Старые и новые предметы могут
занимать разные стаки. Выключение настройки не снимает модель с уже выданных
новых предметов. Клиентская проверка ещё не проводилась. При будущем обновлении
пользовательский серверный пак нужно сохранить и объединить, не перезаписывая.
