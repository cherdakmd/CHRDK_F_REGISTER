# Текстуры новых наград перерождения

Для трёх штатных наград из `rebirth.unique-items` подготовлены отдельные
модели: сердце, звезда и яйцо. Они назначаются только новым выдачам при
`textures.rebirth-items: true`; по умолчанию опция выключена. Сначала нужен
актуальный общий пак и клиентская проверка. Старые предметы не изменяются.

Привязка действует только для точного штатного набора ID, материала, названия
и описания. Если владелец изменил любой из них либо добавил свой предмет, его
настройки сохраняются без автоматической подстановки другой модели. Внешний
вид не участвует в выборе награды, идентификаторах истории или расчётах.
Старые и новые варианты могут не стаковаться; выключение опции не снимает
модели с уже выданных предметов.
