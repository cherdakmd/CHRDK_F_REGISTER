# Иллюстрация для постеров

`world-background.jpg` — AI-иллюстрация, созданная для этой задачи и выбранная
владельцем проекта 2026-11-01 из двух вариантов. Это не скриншот игрового сервера
и не копия чужой карты. Сцена с уютным домом, рекой и горами служит общим фоном;
заголовок и подпись наносятся локально через Pillow, без генерации каждого поста
платным внешним API. Формат1280×720, JPEG quality92; оригинал не хранится в Git.
Карточки публикуются как иллюстрации, не доказательство построек живого мира.
Шрифт DejaVu берётся из системного пакета и в репозиторий не копируется.
