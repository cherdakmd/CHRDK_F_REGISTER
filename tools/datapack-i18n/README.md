**Да, перевод возможен.** Присланный файл `mine-treasure-1.6.5 (1).txt` — это не текст, а
обычный ZIP-архив, которому по ошибке дали расширение `.txt` (первые байты `PK\x03\x04`).
Внутри — датапак для Minecraft 1.21.1 (`pack_format` 121): 3033 записи, из них 2657 файлов.

## Важная особенность датапаков

В датапаке **нет** `assets/<namespace>/lang/*.json`. Языковые файлы живут в *ресурспаках*,
а датапак хранит весь видимый игроку текст **литералами прямо в командах и JSON**:

- `tellraw`, `title ... actionbar` в `.mcfunction`;
- `CustomName` у мобов, пункты меню `{"display":{"text":...}}`;
- `"title"` / `"description"` в достижениях;
- `"fallback"` в зачарованиях;
- `"text"` внутри `set_name` / `set_lore` в таблицах добычи;
- страницы книги-путеводителя в `loot_table/inject/inject.json`;
- описание самого пака в `pack.mcmeta`.

Поэтому перевод — это не «добавить lang-файл», а аккуратно заменить эти литералы,
**не тронув** идентификаторы (`minecraft:stone`, `#mt:armor`, `mt.var`, `$vanilla_mode`,
`@s`, имена функций, команд, счётчиков). Именно это делает `localize.py`.

Всего найдено **1393 уникальных строки / 7346 вхождений**. Переведено 1393 (100 %).

## Что получилось

| Файл | Описание |
|---|---|
| `datapack-ru/mine-treasure-1.6.5-ru.zip` | **Готовый переведённый датапак.** Класть в `world/datapacks/` |
| `datapack-ru/mine-treasure-1.6.5-source.zip` | Оригинальный архив (копия присланного `.txt` с правильным расширением) |

| `translations_ru.py`, `translations_ru_part2.py` | Исходник глоссария в виде Python-словаря (удобно править строки с `\n`) |
| `localize.py` | Извлечение / сборка / отчёт |

## Как пользоваться

```bash
cd tools/datapack-i18n

# 1. Пересобрать глоссарий из исходника (сохранив ручные правки)
python3 translations_ru.py                       # перегенерировать ru.json из Python-словарей
python3 localize.py extract \
    --source ../../datapack-ru/mine-treasure-1.6.5-source.zip \
    --out ru.json --glossary ru.json            # дополнить новыми строками, если пак обновился

# 2. Проверить покрытие
python3 localize.py report \
    --source ../../datapack-ru/mine-treasure-1.6.5-source.zip \
    --glossary ru.json

# 3. Собрать переведённый архив
python3 localize.py build \
    --source ../../datapack-ru/mine-treasure-1.6.5-source.zip \
    --glossary ru.json \
    --out ../../datapack-ru/mine-treasure-1.6.5-ru.zip
```

`--source` принимает как ZIP, так и распакованную папку. Если `--out` оканчивается на
`.zip`, результат упаковывается (порядок записей и папки сохраняются); иначе создаётся
распакованная папка — удобно для отладки на сервере.

### Как устроен переводчик

- `text`, `fallback`, `item_name`, `custom_name`, `title`, `description` — всегда текст;
- `name` / `lore` — только внутри функций `set_name` / `set_lore` (иначе это ID предмета!);
- строки-маркеры (`#disable_*`, `$vanilla_mode`, `minecraft:*`, `@s`, `mt.*`) не трогаются;
- повторяющиеся семьи строк переводятся правилами: названия сокровищ («Legendary Badlands
  Treasure» → «легендарное сокровище Бесплодных земель»), статы («12 Attack Damage» →
  «12 урона атаки»), достижения вида «Find your first … Treasure!» и «Find 100 Rare Treasure!»;
- всё остальное — из `ru.json`;
- пробельные отступы в начале/конце строк сохраняются (они используются для форматирования);
- битые строки с двойной UTF-8 кодировкой (`Ã¢â€¦`) починены.

## Установка на сервер

1. Скопируйте `mine-treasure-1.6.5-ru.zip` в `<мир>/datapacks/`.
2. `/datapack list`, затем `/datapack enable "file/mine-treasure-1.6.5-ru.zip"`.
3. `/reload`. Русский язык у клиента **не обязателен** — текст лежит литералами в самом паке.

## Известные ограничения

- Русские строки в среднем длиннее английских. В книге-путеводителе и в подсказках предметов
  часть текста может обрезаться/переноситься. Лечится правкой `ru.json` (сократите формулировку).
- Каламбуры в названиях достижений переведены адаптивно, а не дословно.
- Бренд `Mine Treasure` и имя автора `Frozytime` оставлены без перевода.
- В `structure/portal_room.nbt` и `pack.png` текста нет — файлы скопированы побайтово.
