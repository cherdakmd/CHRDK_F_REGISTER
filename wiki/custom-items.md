## Состояние

**CHRDK_CustomItems — экспериментальный аддон**, не готовый игровой набор.
Конфиг `catalog.yml` по умолчанию пуст, но пять встроенных предметов
присутствуют в каталоге всегда. Поддерживаются описания брони (`armor`),
оружия (`weapon`), инструментов (`tool`) и расходников (`consumable`).
Запись требует стабильный идентификатор, совместимый базовый материал и путь
будущей модели `chrdk_items:item/`, необязательные название и до четырёх строк
описания. Текст не исполняется как разметка. Для расходников разрешены только нейтральные
материалы: `PAPER`, `CLAY_BALL`, `ECHO_SHARD`, `AMETHYST_SHARD`,
`PRISMARINE_CRYSTALS`. Ошибка каталога отключает аддон.

Игрокам доступна бесплатная витрина **только для чтения**: `/customitems`
открывает GUI с категориями, страницами, описаниями и текстурами (если пакет
установлен); предметы из меню забрать нельзя. Команды
`/customitems weapon`, `/customitems armor`, `/customitems tool`,
`/customitems consumable` и `/customitems all 2` для выбора страницы.
`/customitems info <id>` показывает описание и категорию. Витрина не выдаёт
предметы и не изменяет инвентарь; дополнительный каталог по умолчанию пуст. Право
`chrdkcustomitems.use` по умолчанию разрешено всем.

### Лопата в говне

`mud_shovel` — железная лопата с собственной текстурой; тестовая выдача
`/customitemsadmin give mud_shovel` только администратору и только себе. Пока
предмет в **основной руке**, он даёт Скорость I и Регенерацию I, блокирует
эффект и урон **отравления (Poison)** и снимает действующее отравление. Эффект
не защищает от иссушения, мгновенного урона или других зелий. Пассивы
согласуются с другими эффектами через общее ядро, а не должны удалять чужие
усиления; поведение и переключение руки необходимо проверить на сервере. Рецепта
и обычного игрового способа получения пока нет. Метки PDC не являются защитой
от подделки предметов, поэтому использовать предмет на production рано.

### Лопатка для лотка и три инструмента

Все четыре имеют собственные текстуры и выдаются только администратору себе
на тестовом сервере: `/customitemsadmin give <id>`. Рецептов пока нет.

| ID | Предмет и свойство |
| --- | --- |
| `litter_scoop` | Лопатка для лотка: **Замедление I и Ночное зрение I** при удержании в основной руке. В другой руке или инвентаре эффекты не работают. |
| `cat_finder` | Кошачий следопыт: показывает расстояние до ближайшей загруженной кошки в радиусе 16 блоков. |
| `spawn_guide` | Топор путеводителя: показывает координаты спавна текущего мира (не персональной кровати). |
| `weather_gauge` | Погодная кирка: показывает текущую погоду и приблизительное время до смены состояния осадков; игровые правила могут остановить её смену. |

Для трёх инструментов возьмите предмет в основную руку и нажмите **правую
кнопку мыши**: в воздухе или по разрешённому блоку. Если защита запретила
взаимодействие с блоком, свойство не сработает; задержка между применениями —
одна секунда. Команда не нужна (прежняя `/customitems use` сохранена для
совместимости). Их свойства доступны независимо от `prototype-properties`,
не расходуют предмет и не меняют мир; `litter_scoop` работает пассивно без команды.
Базовые ванильные материалы и поведение инструментов сохранены; новые боевые
коэффициенты не добавлены. Как и другие предметы аддона, они экспериментальны:
PDC не доказывает происхождение, работа на сервере и взаимодействие со сторонними
эффектами требуют проверки.

### Ранее подготовленные макеты

В примере каталога — по три предмета каждой категории:

| Категория | Прототипы (ID) |
| --- | --- |
| Оружие | `test_blade`, `test_sunblade`, `test_moonblade` |
| Броня | `test_helm`, `test_chest`, `test_boots` |
| Инструменты | `test_pick`, `test_shovel`, `test_hoe` |
| Расходники | `test_scroll`, `test_rune`, `test_charm` |

Это учебные прототипы: базовые ванильные материалы и их обычные характеристики
различаются. Есть по одному небоевому информационному свойству на каждый предмет:

| Предмет | Тестовое свойство |
| --- | --- |
| `test_blade` | Направление взгляда |
| `test_sunblade` | Время мира |
| `test_moonblade` | Игровой день мира |
| `test_helm` | Освещённость около игрока |
| `test_chest` | Сытость игрока |
| `test_boots` | Высота игрока |
| `test_pick` | Тип видимого блока в пределах 5 блоков |
| `test_shovel` | Освещение небом у игрока |
| `test_hoe` | Текущий биом |
| `test_scroll` | Одноразово показывает координаты и мир |
| `test_rune` | Одноразово показывает уровень опыта |
| `test_charm` | Одноразово показывает свою точку возрождения |

Свойства включаются только для стенда через `prototype-properties: true`. Взять
предмет в основную руку и выполнить `/customitems use`; броню для активации тоже
нужно держать в руке, пассивных эффектов при ношении пока нет. Три расходника
списываются по одному, включая в творческом режиме; если точка возрождения не
установлена или данные не получены, списания нет. Это не боевые бонусы и не
готовая система предметов. По умолчанию свойства выключены.

На тестовом сервере администратор с правом `chrdkcustomitems.admin` может
выдать **себе один прототип** командой `/customitemsadmin give <id>` после
настройки каталога и перезапуска. Выдача требует свободную ячейку обычного
инвентаря; при её отсутствии предмет не выдаётся и не выбрасывается. Предмет
получает метку идентификатора и версии и тестовое название; эти метки не
являются доказательством подлинности. Права по умолчанию у операторов.

**Крафты пока не реализованы.** Кроме описанной лопаты, боевые свойства макетов не реализованы.
Добавлен отдельный экспериментальный ресурс-пак с текстурами встроенных предметов и двенадцати макетов
и примером каталога. При первом запуске пакет сохраняется в
`plugins/CHRDK_CustomItems/custom-items-pack.zip` и не перезаписывается при
обновлениях. Его может раздавать встроенный HTTP-сервер прямо с Minecraft-сервера.
В `config.yml` укажите публичный адрес, например
`resource-pack.url: "http://example.com:8123/custom-items-pack.zip"`, включите
`resource-pack.host.enabled: true`, откройте TCP 8123 и настройте NAT, если нужно.
Путь должен быть именно `/custom-items-pack.zip`. Адрес должен быть доступен
клиентам снаружи, не `localhost`; панель хостинга может потребовать выделенный
порт. Пока URL не задан или порт не удалось занять, предложение не отправляется.
Встроенный сервер принимает только GET/HEAD указанного файла; публичный HTTP
не шифруется. Для HTTPS можно поставить обратный прокси. Альтернатива — выключить
встроенную раздачу и использовать прежний внешний HTTPS URL (файл должен быть
идентичен локальному). SHA-1 рассчитывается из снимка ZIP при запуске, который
раздаётся до остановки; после замены файла необходим перезапуск. Старые
конфиги сохраняются: для включения раздачи добавьте раздел `host` вручную.
`resource-pack.required: false` по умолчанию — игрок может отказаться и остаться;
при `true` клиенту требуется пакет и отказ может отключить его. Прототипные текстуры выключены по умолчанию. При включении выдаются только двенадцать точных примеров с
`CustomModelData` 810001; встроенные предметы используют 810003 либо 810005 независимо от этой опции.
Без пакета клиент показывает базовые предметы. У
надетой брони остаются обычные модели. Другие ресурс-паки могут
конфликтовать: не устанавливайте этот пакет на действующий сервер без аудита и
объединения. Процедура закрытого испытания — `custom-items/SMOKE-TEST.md`.
Предметы сохраняют обычное ванильное поведение базового материала. На боевом сервере их не
использовать: взаимодействия с крафтом, чарами, артефактами и сохранность ещё
не проверены. Системы ролей в пати не предусмотрено: игрок сам выбирает свой
стиль. Игровые эффекты и баланс согласуются отдельно.
