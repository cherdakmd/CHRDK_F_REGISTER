title: "Карточка игрока"
description: "Вся статистика в одном меню: ранг, прогресс, экономика и достижения."
---

`/profile` собирает прогресс из всех аддонов в одну карточку. Раньше за каждым
числом нужно было идти в отдельную команду — теперь всё видно сразу.

## Что видно

- 54 слота: голова игрока по центру, до 21 раздела, кнопки «В чат»,
  «Оформление ника» (только в своей карточке), «Обновить» и «Закрыть».
- Клик по разделу закрывает меню и печатает его строки в чат.
- `/profile chat [ник]` выводит всё текстом.
- `/profile <ник>` показывает публичную карточку другого игрока — даже
  офлайн.

## Разделы

| Аддон | Что показывает |
|---|---|
| ядро | ранг и срок, пароль, 2FA, банк, покупки каталога |
| оформление ника | сколько надписей включено и какие скрыты (своя карточка) |
| `CHRDK_Hunt` | монеты, звание, убийства, трофеи, осколки, ключи |
| `CHRDK_Orders` | репутация, звание, сданные заказы |
| `CHRDK_Achievements` | открытые достижения, награды, бейдж |
| `CHRDK_Skills` | суммарный уровень, опыт, лучший навык |
| `CHRDK_Classes` | класс, уровень, очки, таланты |
| `CHRDK_Pets` | живые питомцы и старший по уровню |
| `CHRDK_Ranks` | часы игры, звание, остаток до следующего |
| `CHRDK_Claims` | приваты из лимита и казна |
| `CHRDK_Party` | состав группы и потенциал бонуса |
| `CHRDK_Events` | идущее событие и сколько осталось |
| `CHRDK_Quests` | фракция, ранг, репутация, задания |
| `CHRDK_BattlePass` | очки сезона, задания, награды |
| `CHRDK_Streams` | часы буста за эфиры, минуты, каналы |
| `CHRDK_DailyRewards` | стрик и напоминание |

Если аддона нет, его раздел просто не появляется. Пустые разделы ядро скрывает
само: новичок не видит «0 из 0».

## Команды

| Команда | Что делает |
|---|---|
| `/profile` | своя карточка |
| `/profile <ник>` | карточка другого игрока |
| `/profile chat [ник]` | всё текстом в чат |
| кнопка «Оформление ника» | меню `/labels`: каждая надпись включается отдельно |

## Оформление ника (1.4.186)

В своей карточке есть раздел «Оформление ника»: видно, сколько надписей
включено из восьми и какие именно скрыты. Кнопка рядом открывает меню, где
каждое звание — ранг, титул кузни, класс, гильдия,
стример, квесты, достижения и шапка таба — переключается отдельно. Подробнее —
`ranks.md`.

## Зачем это нужно

- **Быстрая проверка прогресса.** Не нужно открывать пять меню, чтобы понять,
  где вы отстаёте.
- **Помощь новичкам.** Опытный игрок может посмотреть карточку и подсказать,
  что качать.
- **Проверка перед покупкой.** Видно, какие покупки каталога уже активны.

> **Карточка — не рейтинг.** Она показывает ваш прогресс, а не сравнивает вас
> с другими. Рейтинги живут в отдельных командах: `/baltop`, `/hunt top`,
> `/tiers collection top`.
