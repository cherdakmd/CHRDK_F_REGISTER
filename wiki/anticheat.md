## Суть

Сервер защищён античитом: все классы читов (движение, бой, пакеты, чат, краш-эксплойты) под наблюдением с первого дня. Подозрительные действия попадают в алерты модераторов и в журнал доказательств. Античит **не банит автоматически**: запрет выносит человек по журналу.

Правила одинаковы для всех — исключений нет ни у кого, включая персонал и OP. Персоналу не выдаются права обхода античита.

## Алерты модераторам

- Алерты приходят в чат всем с правом модератора; дубликаты по игроку и типу нарушения схлопываются, чтобы не заливать чат.
- Команда **/ac alerts** — включить или выключить алерты лично для себя (полезно на смене без разбора).

## Разбор: /ac

| Команда | Что делает |
| --- | --- |
| **/ac history \<ник\>** | карточка нарушителя: итоги, топ-чеки, последние локации и лента срабатываний |
| **/ac top** | топ суток по числу срабатываний |
| **/ac alerts** | личные алерты вкл/выкл |
| **/ac reload** | перечитать настройки моста (для администрации) |

Срабатывание выглядит так: `Сработал античит: Ник, KillauraB ×3, пинг 42 мс` — клик по сообщению открывает карточку.

## Журнал доказательств

Каждое срабатывание пишется в журнал с временем, ником, проверкой, уровнем, пингом, TPS, миром и координатами — это и есть доказательная база для запрета и для разбора апелляций. Данные хранятся месяц; суточные архивы ведутся автоматически.

## Чего античит не делает

- Не банит и не кикает сам — запрет выносит человек по журналу;
- не выносит приговор по одному срабатыванию: случайный флаг не равен читу, решение принимают по карточке и истории.
