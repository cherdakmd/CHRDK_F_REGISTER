# Новые книги-путеводители

В Core `guide.textures.book-item: false` по умолчанию. При включении новые книги,
выданные новичкам и через `/guide`, получают отдельную модель из общего ресурс-пака.
Текст, автор, страницы, права и условия выдачи не меняются. Существующие книги не
сканируются и не переоформляются; отключение опции не удаляет выданные модели.
Публичный `createBook(content)` сохраняет прежнее поведение без модели.

Сначала установить актуальный объединённый пак, не перезаписывая пользовательский
пак без слияния и резервной копии. Проверить внешний вид и открытие книги в клиенте:
автоматический тест не подтверждает отображение.
